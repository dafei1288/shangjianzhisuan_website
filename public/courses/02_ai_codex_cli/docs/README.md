# Codex CLI 实战课程

> 20 章实战课程，掌握 OpenAI Codex CLI 从安装到生产级使用。

## 课程简介

本课程系统讲解 OpenAI Codex CLI——一个基于终端的 AI 编程助手。从安装认证到高级工作流，从基础配置到 MCP 工具扩展，从日常开发到 CI/CD 集成，全面掌握 Codex CLI 的核心能力。

## 技术栈

- **Node.js 22+** / npm
- **OpenAI GPT-5-Codex** 模型
- **MCP (Model Context Protocol)**
- **bash / shell**

## 课程特色

- 🚀 **20 章完整覆盖**：从入门到生产级使用
- 🔧 **实战导向**：每章都有可操作的命令示例
- 🔒 **安全优先**：沙箱机制、审批模式、权限管理
- 🔌 **可扩展**：MCP 工具协议、自定义 Server 开发

## 快速开始

```bash
# 安装 Codex CLI
npm install -g @openai/codex

# 设置 API Key
export OPENAI_API_KEY=your_key

# 启动
codex
```
