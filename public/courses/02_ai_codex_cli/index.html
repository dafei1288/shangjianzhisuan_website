// 审批模式

你决定 AI 的自主权

三种审批模式，从完全人工审核到全自动执行，根据任务风险灵活切换。

🔍
Suggest
codex --approval suggest
默认模式。Codex 分析代码、提出建议，每一步操作都需要你手动确认后才执行。最安全，适合学习阶段或高风险操作。
  • 读取文件，展示 diff，等待确认
  • 每个 shell 命令都需要审批
  • 适合：陌生代码库、生产环境
✏️
Auto Edit
codex --approval auto-edit
平衡模式。Codex 自动读取和修改文件，但执行 shell 命令前仍需确认。适合日常开发，兼顾效率与安全。
  • 自动应用文件编辑，无需逐一确认
  • 网络访问和 shell 命令仍需审批
  • 适合：日常功能开发、重构
⚡
Full Auto
codex --approval full-auto
全自动模式。Codex 在沙箱内自主完成所有操作，包括运行命令、修改文件，无需人工干预。适合 CI/CD 和批量任务。
  • 完全自主执行，沙箱隔离保护系统
  • 适合：CI 流水线、非交互式脚本
  • 配合 AGENTS.md 约束行为边界
// AGENTS.md

给 AI 写工作手册

AGENTS.md 是放在项目根目录的 Markdown 文件，Codex 每次启动都会读取它，作为项目级别的持久化指令。

  • 定义代码风格、命名规范、禁止操作
  • 注入项目背景、技术栈、架构说明
  • 支持层级结构：全局 → 项目 → 子目录
  • 优先级：子目录 AGENTS.md > 项目根 > 全局
AGENTS.md
# 项目规范
 
## 技术栈
- TypeScript 5.x + Node.js 22
- 测试框架：Vitest
- 包管理：pnpm
 
## 代码规范
- 函数命名使用 camelCase
- 每个函数必须有 JSDoc 注释
- 禁止使用 any 类型
 
## 禁止操作
- 不得修改 .env 文件
- 不得删除 tests/ 目录
- 提交前必须运行 pnpm test
