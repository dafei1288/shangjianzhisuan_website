# 第18章 项目感知与代码理解 — ProjectScanner 与上下文注入

## 教学目标

1. 实现 `ProjectScanner` 类，自动扫描目录树、检测技术栈、识别关键文件
2. 掌握项目上下文的 token 预算控制策略（不盲目注入所有信息）
3. 将扫描结果动态注入 system prompt，让 Agent 具备项目感知能力
4. 理解按需加载 vs 预加载的权衡

## 课前准备

- 已完成第 13 章 System Prompt 设计和第 14 章 Token 预算管理
- 准备一个包含多种文件类型的真实项目作为测试对象（Python + JS 混合项目最佳）
- 理解常见项目结构约定（入口文件、配置文件、测试目录的命名惯例）

## 核心概念

### 项目感知 = Agent 的"视野"

没有项目感知的 Agent 就像一个刚入职的员工，对项目一无所知，每次提问都要从头了解。有项目感知的 Agent 就像一个已经看过项目文档的员工，能够直接给出精准的回答和建议。

```
无项目感知:
  用户: "这个项目的入口在哪？"
  Agent: "我需要先看一下目录结构..."
  Agent: [调用 read_file 多次]
  Agent: [调用 run_bash("ls") 多次]

有项目感知:
  用户: "这个项目的入口在哪？"
  Agent: "根据项目结构，这是一个 Python FastAPI 应用，入口是 app/main.py。"
```

### 扫描内容与优先级

不是所有项目信息都值得注入 system prompt。需要根据信息价值排序：

```
优先级 1 (必须): 目录结构树 (depth=2)、技术栈检测、项目根路径
优先级 2 (重要): 入口文件内容、README 摘要、CLAUDE.md/AGENTS.md
优先级 3 (可选): 测试文件列表、构建脚本内容、依赖列表
优先级 4 (按需): 完整的源代码文件（仅在需要时读取）
```

### Token 预算控制

项目上下文的总 token 控制在 1500 以内（约占总预算的 1-2%）。目录树限制在 60 行以内，每个关键文件内容限制在 50 行以内。超出部分通过截断 + 摘要处理。

## 代码讲解

### 18.1 项目扫描数据结构

```python
from dataclasses import dataclass, field
from pathlib import Path
from typing import Optional
import os
import logging

logger = logging.getLogger(__name__)


@dataclass
class ProjectInfo:
    """项目扫描结果"""
    root_path: str = ""
    directory_tree: str = ""
    languages: list[str] = field(default_factory=list)
    frameworks: list[str] = field(default_factory=list)
    build_tools: list[str] = field(default_factory=list)
    entry_files: list[str] = field(default_factory=list)
    key_files: dict[str, str] = field(default_factory=dict)  # filename -> content
    test_directories: list[str] = field(default_factory=list)
    total_files: int = 0
    total_dirs: int = 0
    scan_time_ms: float = 0

    def to_context_text(self) -> str:
        """将项目信息格式化为可注入 prompt 的文本"""
        parts = []
        parts.append(f"工作目录: {self.root_path}")
        parts.append(f"技术栈: {', '.join(self.languages)}")
        if self.frameworks:
            parts.append(f"框架: {', '.join(self.frameworks)}")
        if self.build_tools:
            parts.append(f"构建工具: {', '.join(self.build_tools)}")
        if self.entry_files:
            parts.append(f"入口文件: {', '.join(self.entry_files)}")
        if self.test_directories:
            parts.append(f"测试目录: {', '.join(self.test_directories)}")

        parts.append(f"\n项目结构:\n```\n{self.directory_tree}\n```")

        # 关键文件内容
        for filename, content in self.key_files.items():
            truncated = content[:1500]
            if len(content) > 1500:
                truncated += "\n... [已截断]"
            parts.append(f"\n--- {filename} ---\n{truncated}")

        return "\n".join(parts)
```

### 18.2 ProjectScanner 核心实现

```python
class ProjectScanner:
    """
    项目扫描器。
    扫描目录结构、识别技术栈、定位关键文件。
    所有扫描结果汇总为 ProjectInfo，可注入 system prompt。
    """

    # 跳过的目录
    SKIP_DIRS = {
        ".git", "node_modules", "__pycache__", "venv", ".venv",
        "dist", "build", ".next", ".nuxt", "target", ".idea",
        ".vscode", ".cache", "coverage", ".tox", "egg-info",
    }

    # 跳过的文件
    SKIP_FILES = {
        ".DS_Store", "Thumbs.db", "*.pyc", "*.pyo",
        "*.so", "*.dll", "*.exe", "*.bin",
    }

    # 技术栈标记文件 -> (语言, 构建工具)
    TECH_MARKERS = {
        "requirements.txt": ("Python", "pip"),
        "pyproject.toml": ("Python", "poetry/pdm"),
        "setup.py": ("Python", "setuptools"),
        "Pipfile": ("Python", "pipenv"),
        "package.json": ("JavaScript/TypeScript", "npm"),
        "pnpm-lock.yaml": ("JavaScript/TypeScript", "pnpm"),
        "yarn.lock": ("JavaScript/TypeScript", "yarn"),
        "Cargo.toml": ("Rust", "cargo"),
        "go.mod": ("Go", "go modules"),
        "pom.xml": ("Java", "Maven"),
        "build.gradle": ("Java", "Gradle"),
        "Gemfile": ("Ruby", "bundler"),
        "composer.json": ("PHP", "composer"),
    }

    # 入口文件候选
    ENTRY_FILE_PATTERNS = [
        "main.py", "app.py", "manage.py", "wsgi.py", "asgi.py",
        "index.ts", "index.js", "index.tsx", "index.jsx",
        "main.rs", "lib.rs", "main.go", "Main.java",
        "src/main.py", "src/app.py", "src/index.ts",
        "app/main.py", "app/main.ts",
    ]

    # 关键配置文件（优先加载到上下文）
    KEY_CONFIG_FILES = [
        "CLAUDE.md", "AGENTS.md", ".cursorrules",
        "README.md", "CONTRIBUTING.md",
    ]

    def __init__(self, max_tree_depth: int = 2, max_tree_lines: int = 60):
        self.max_tree_depth = max_tree_depth
        self.max_tree_lines = max_tree_lines

    def scan(self, project_dir: str = ".") -> ProjectInfo:
        """执行完整的项目扫描"""
        import time
        start = time.time()

        root = Path(project_dir).resolve()
        info = ProjectInfo(root_path=str(root))

        # 1. 扫描目录树
        info.directory_tree = self._scan_directory_tree(root)
        info.total_files, info.total_dirs = self._count_items(root)

        # 2. 检测技术栈
        languages, build_tools = self._detect_tech_stack(root)
        info.languages = languages
        info.build_tools = build_tools

        # 3. 检测框架
        info.frameworks = self._detect_frameworks(root)

        # 4. 定位入口文件
        info.entry_files = self._find_entry_files(root)

        # 5. 定位测试目录
        info.test_directories = self._find_test_directories(root)

        # 6. 加载关键配置文件
        info.key_files = self._load_key_files(root)

        info.scan_time_ms = (time.time() - start) * 1000
        logger.info(
            f"项目扫描完成: {info.total_files} 文件, "
            f"{info.total_dirs} 目录, 耗时 {info.scan_time_ms:.0f}ms"
        )

        return info

    def _scan_directory_tree(self, root: Path) -> str:
        """生成目录树"""
        lines = []
        for dirpath, dirnames, filenames in os.walk(root):
            # 跳过指定目录
            dirnames[:] = [
                d for d in dirnames
                if d not in self.SKIP_DIRS and not d.startswith(".")
            ]
            dirnames.sort()

            depth = Path(dirpath).relative_to(root).parts.__len__()
            if depth > self.max_tree_depth:
                dirnames.clear()
                continue

            indent = "  " * depth
            dirname = os.path.basename(dirpath) or str(root.name)
            lines.append(f"{indent}{dirname}/")

            # 每个目录最多显示 15 个文件
            for f in sorted(filenames)[:15]:
                if not any(f.endswith(ext.replace("*", ""))
                           for ext in self.SKIP_FILES if "*" in ext):
                    lines.append(f"{indent}  {f}")

            if len(lines) > self.max_tree_lines:
                lines.append(f"{indent}  ... (已省略)")
                break

        return "\n".join(lines)

    def _detect_tech_stack(self, root: Path) -> tuple[list[str], list[str]]:
        """从标记文件推断技术栈"""
        languages = []
        build_tools = []

        for filename, (lang, tool) in self.TECH_MARKERS.items():
            if (root / filename).exists():
                if lang not in languages:
                    languages.append(lang)
                if tool not in build_tools:
                    build_tools.append(tool)

        return languages, build_tools

    def _detect_frameworks(self, root: Path) -> list[str]:
        """从依赖文件推断框架"""
        frameworks = []

        # Python 框架
        req_file = root / "requirements.txt"
        if req_file.exists():
            content = req_file.read_text(encoding="utf-8", errors="ignore").lower()
            if "django" in content:
                frameworks.append("Django")
            if "flask" in content:
                frameworks.append("Flask")
            if "fastapi" in content:
                frameworks.append("FastAPI")

        # JavaScript/TypeScript 框架
        pkg_file = root / "package.json"
        if pkg_file.exists():
            try:
                import json
                pkg = json.loads(pkg_file.read_text(encoding="utf-8"))
                deps = {**pkg.get("dependencies", {}),
                        **pkg.get("devDependencies", {})}
                if "react" in deps:
                    frameworks.append("React")
                if "vue" in deps:
                    frameworks.append("Vue")
                if "next" in deps:
                    frameworks.append("Next.js")
                if "express" in deps:
                    frameworks.append("Express")
            except Exception:
                pass

        return frameworks

    def _find_entry_files(self, root: Path) -> list[str]:
        """定位入口文件"""
        found = []
        for pattern in self.ENTRY_FILE_PATTERNS:
            candidate = root / pattern
            if candidate.exists() and candidate.is_file():
                found.append(pattern)
        return found

    def _find_test_directories(self, root: Path) -> list[str]:
        """定位测试目录"""
        test_dirs = []
        for name in ["tests", "test", "__tests__", "spec"]:
            if (root / name).is_dir():
                test_dirs.append(name)
        return test_dirs

    def _load_key_files(self, root: Path) -> dict[str, str]:
        """加载关键配置文件"""
        key_files = {}
        for filename in self.KEY_CONFIG_FILES:
            filepath = root / filename
            if filepath.exists() and filepath.is_file():
                try:
                    content = filepath.read_text(encoding="utf-8", errors="ignore")
                    key_files[filename] = content[:2000]  # 每个文件最多 2000 字符
                except Exception:
                    pass
        return key_files

    def _count_items(self, root: Path) -> tuple[int, int]:
        """统计文件和目录数量"""
        files = 0
        dirs = 0
        for dirpath, dirnames, filenames in os.walk(root):
            dirnames[:] = [d for d in dirnames if d not in self.SKIP_DIRS]
            dirs += len(dirnames)
            files += len(filenames)
        return files, dirs
```

### 18.3 上下文注入与 System Prompt 集成

```python
class ProjectContextInjector:
    """
    将 ProjectInfo 注入 System Prompt。
    控制 token 预算，确保项目上下文不会占满整个 prompt。
    """

    def __init__(self, max_context_tokens: int = 1500, token_counter=None):
        self.max_context_tokens = max_context_tokens
        self.token_counter = token_counter
        self._cached_info: Optional[ProjectInfo] = None
        self._cache_root: Optional[str] = None

    def get_project_context(self, project_dir: str = ".") -> str:
        """
        获取项目上下文文本。
        使用缓存避免重复扫描。
        """
        abs_root = str(Path(project_dir).resolve())

        # 检查缓存
        if self._cache_root == abs_root and self._cached_info is not None:
            return self._format_context(self._cached_info)

        # 执行扫描
        scanner = ProjectScanner()
        info = scanner.scan(project_dir)
        self._cached_info = info
        self._cache_root = abs_root

        return self._format_context(info)

    def _format_context(self, info: ProjectInfo) -> str:
        """格式化项目上下文，控制 token 预算"""
        context_text = info.to_context_text()

        # 如果有 token 计数器，检查是否超预算
        if self.token_counter:
            tokens = self.token_counter.count_text(context_text)
            if tokens > self.max_context_tokens:
                # 策略：先去掉关键文件内容，再截断目录树
                info_copy = ProjectInfo(
                    root_path=info.root_path,
                    directory_tree=info.directory_tree[:800],
                    languages=info.languages,
                    frameworks=info.frameworks,
                    build_tools=info.build_tools,
                    entry_files=info.entry_files,
                )
                context_text = info_copy.to_context_text()

        return f"\n## 项目信息\n{context_text}"

    def invalidate_cache(self):
        """手动使缓存失效（文件结构变更后调用）"""
        self._cached_info = None
        self._cache_root = None
```

### 18.4 与 SystemPromptBuilder 集成

```python
# 在 SystemPromptBuilder 中集成项目感知的完整示例

def build_agent_prompt(
    project_dir: str = ".",
    prompt_level: PromptLevel = PromptLevel.STANDARD,
    token_counter=None,
) -> str:
    """构建包含项目感知的完整 System Prompt"""

    # 1. 构建基础 prompt（角色 + 规则 + 格式）
    builder = SystemPromptBuilder(prompt_level)

    # 2. 获取项目上下文
    injector = ProjectContextInjector(
        max_context_tokens=1500,
        token_counter=token_counter,
    )
    project_context = injector.get_project_context(project_dir)

    # 3. 将项目上下文作为动态上下文注入
    # 复用第 13 章的 DynamicContext 类或直接作为扩展
    builder.add_extension(project_context)

    # 4. 构建最终 prompt
    return builder.build()
```

## 常见问题

### Q1: 大型项目的目录树太长怎么办？

通过 `max_tree_depth` 和 `max_tree_lines` 参数控制。depth=2 意味着只展示两层目录结构，每层最多 15 个文件，总行数限制在 60 行以内。对于超大型项目，可以只展示 src 目录下的结构，跳过 build/output 等目录。

### Q2: 如何处理 monorepo？

monorepo 通常有多个子项目（如 packages/client、packages/server）。每个子项目有自己的 package.json 和入口文件。扫描时应该识别 monorepo 结构（根目录有 lerna.json 或 pnpm-workspace.yaml），并为每个子项目分别生成上下文。

### Q3: 扫描耗时影响启动速度？

首次扫描的耗时取决于项目大小。通常在 100-500ms 之间。通过缓存机制，后续请求直接使用缓存结果。如果启动速度敏感，可以将扫描放在后台线程中进行，先显示欢迎界面，扫描完成后动态更新 system prompt。

### Q4: 如何判断哪些文件是"关键"的？

基于约定：README.md 是项目说明，CLAUDE.md 是 Agent 指令，配置文件（package.json、pyproject.toml）包含技术栈信息。入口文件通过命名惯例（main.py、index.ts）识别。如果项目有 .editorconfig 或 .prettierrc，也可以作为代码规范的参考。

## 本章小结

本章实现了 `ProjectScanner`，它让 Agent 在启动时就能"看到"项目的全貌。扫描内容包括目录结构、技术栈、框架、入口文件、测试目录和关键配置文件。`ProjectContextInjector` 负责将扫描结果注入 system prompt，同时控制 token 预算确保不会过度占用。通过缓存机制避免重复扫描。有了项目感知能力，Agent 可以更快、更准确地响应用户的编码请求，而不需要每次都从头了解项目。
