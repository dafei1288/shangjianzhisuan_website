## 🔧 Step-by-Step 实操

## 1. 短视频是怎么做出来的？

### 1.1 一条视频的诞生

你可能每天刷到很多短视频。但你有没有想过，每条视频背后都经历了什么？

```mermaid
flowchart LR
    A["💡 选题"] --> B["📝 写脚本"]
    B --> C["🎬 收集素材"]
    C --> D["🎤 配音/录制"]
    D --> E["✂️ 剪辑合成"]
    E --> F["📺 导出发布"]
```

### 1.2 每个环节 AI 能帮什么忙？

| 环节 | 没有 AI | 有 AI |
|------|---------|-------|
| 选题 | 自己想，想半天 | AI 给 10 个选题方向，你挑最感兴趣的 |
| 写脚本 | 一个字一个字写 | AI 生成初稿，你修改润色 |
| 收集素材 | 各处搜索下载 | AI 帮你搜索、筛选、下载 |
| 配音 | 自己录制，需要安静环境 | AI 文字转语音，多种声音可选 |
| 剪辑 | 学习剪辑软件 | AI 生成时间轴，你微调即可 |
| 发布 | 手动打字幕和标题 | AI 生成标题、描述、标签 |

> 🎯 **本章目标**：你将完整走通这 6 个环节，制作出人生中第一条 AI 辅助的短视频！

## 2. 第一步：选题与脚本

### Step 1：选题 —— 小明拍什么？

> 🎬 **场景**：小明想用视频介绍自己创客大赛的项目主题——"AI 绘画"。Codex 帮他头脑风暴。

选题是视频最重要的一步。选题好，成功一半。

```bash
# 在 Codex 对话框中
我是一个中学生，想制作一条科普类短视频发布在 B站/抖音上。
请帮我生成 10 个有趣的选题方向，要求：
1. 选题要贴近同龄人兴趣（科技、游戏、动物、宇宙、冷知识等）
2. 每个选题给出一句话简介
3. 标注难度级别（⭐简单 / ⭐⭐中等 / ⭐⭐⭐挑战）
```

Codex 可能会给你这样的选题列表：

| # | 选题 | 简介 | 难度 |
|---|------|------|------|
| 1 | 为什么天空是蓝色的？ | 3分钟讲清楚光的散射 | ⭐ |
| 2 | 手机是怎么收到信号的？ | 电磁波与基站的故事 | ⭐⭐ |
| 3 | AI 是怎么学会画画的？ | Stable Diffusion 原理趣解 | ⭐⭐⭐ |
| 4 | 宇宙中最可怕的东西 | 黑洞、超新星等天体科普 | ⭐⭐ |
| 5 | 为什么游戏会卡顿？ | GPU、帧率和延迟的秘密 | ⭐⭐ |
| ... | ... | ... | ... |

挑一个你最感兴趣的，我们继续！

### Step 2：写脚本 —— 把想法变成文字

> 🎬 **场景**：小明选好了选题，现在需要把它变成一个 3 分钟的视频脚本。

选好选题后，让 Codex 帮你写脚本：

```bash
我选了选题【为什么天空是蓝色的？】，请帮我写一个视频脚本，要求：

1. 视频总时长：2-3 分钟
2. 脚本格式：分场景写，每个场景包含「画面描述+旁白文字」
3. 语言风格：生动有趣，适合 12-16 岁学生观看
4. 结构：开头吸引注意力 → 主体讲解 → 结尾升华
5. 在关键位置标注需要的图片/动画素材提示

请用 Markdown 表格输出脚本
```

Codex 会生成类似这样的分镜脚本：

| 场景 | 时间 | 画面描述 | 旁白文字 | 素材需求 |
|------|------|----------|----------|----------|
| 1 | 0:00-0:15 | 蓝天白云的延时摄影 | "你有没有想过一个问题——为什么天空是蓝色的？" | 蓝天素材视频 |
| 2 | 0:15-0:40 | 太阳光穿过棱镜的动画 | "要回答这个问题，我们先来认识一下太阳光……" | 棱镜分光动画 |
| 3 | 0:40-1:20 | 大气层粒子散射示意图 | "当阳光遇到地球大气层中的微小粒子……" | 散射原理图解 |
| 4 | 1:20-1:50 | 不同颜色光波长对比图 | "蓝光波长最短，最容易被散射……" | 波谱对比图 |
| 5 | 1:50-2:30 | 日落时的红色天空 | "那为什么日落时天空是红色的呢？" | 日落延时 |
| 6 | 2:30-3:00 | 太空中拍地球的照片 | "现在你知道了吧！下次看到蓝天，可以给朋友讲讲这个知识点！" | 地球照片 |

### 2.3 优化脚本

脚本不是一次就能写好的。继续和 Codex 迭代：

```bash
# 加一点幽默元素
脚本很好！但我觉得可以在开头加一个小笑话或有趣的问题，比如"如果我告诉你天空其实是紫色的，你信吗？"

# 调整节奏
场景 2 的解释太长了，能缩短到 20 秒吗？

# 补充互动环节
在视频结尾加一个互动问题，引导观众在评论区回答
```

---

### Step 3：收集素材 —— 画面从哪来？

### 3.1 素材清单

根据脚本的"素材需求"列，整理出完整的素材清单：

```bash
请根据我上面的视频脚本，整理一份详细的素材清单：
1. 列出每个场景需要的所有素材（图片/视频/动画/音效）
2. 标注每个素材的建议来源（免费图库/自己制作/AI生成）
3. 按优先级排序（必需的 > 锦上添花的）
```

### 3.2 AI 生成图片素材

对于示意图和插画，可以让 Codex 通过 AI 绘图工具生成：

```bash
# 通过 Codex 调用 AI 绘图
请帮我生成一张"太阳光穿过棱镜被分成七色光"的示意图。
风格：科普插画，线条简洁，色彩鲜明
尺寸：16:9 横版
```

### 3.3 搜索免费素材

对于实拍素材，使用免费图库或视频素材库：

```bash
请帮我搜索以下免费素材：
1. 蓝天白云的延时摄影视频（来源：Pexels 或 Pixabay）
2. 日落的延时摄影视频
3. 从太空中拍摄地球的高清照片
4. 轻快的背景音乐（无版权，适合科普视频）

请整理成包含下载链接的清单
```

---

### Step 4：AI 配音 —— 不用自己录音！

### 4.1 文字转语音

不用自己录音！AI 可以帮你把脚本文字变成自然的语音：

```bash
请帮我把以下旁白文字转为语音：
---
你有没有想过一个问题——为什么天空是蓝色的？要回答这个问题，我们先来认识一下太阳光。太阳发出的光看起来是白色的，但其实它包含了红橙黄绿青蓝紫七种颜色。当阳光遇到地球大气层中的微小粒子时，蓝光波长最短，最容易被散射到四面八方。所以我们抬头看到的天空，就是被散射的蓝光啦！
---

要求：
- 使用自然的中文男声/女声（11-13岁少年音如果可选）
- 语速适中，约每分钟 200 字
- 输出 MP3 格式，保存为 voiceover.mp3
```

### 4.2 配乐

好的背景音乐能让视频观感提升一个档次：

```bash
请帮我找一段适合科普短视频的背景音乐：
1. 无版权（可商用）
2. 风格：轻快、有趣、有节奏感但不喧闹
3. 时长：约 3 分钟
4. 保存为 bgm.mp3
```

---

### Step 5：剪辑合成 —— 全部拼起来

> 🎬 **场景**：所有素材就位！小明让 Codex 生成 FFmpeg 命令，一键合成。

### 5.1 用 Codex 生成剪辑脚本

Codex 可以帮你生成 FFmpeg 命令来完成视频合成：

```bash
请帮我生成 FFmpeg 命令，把以下素材合成为一个完整的短视频：

素材列表：
1. bgm.mp3 —— 背景音乐（3分钟，作为背景循环播放）
2. voiceover.mp3 —— AI 配音旁白（2分45秒）
3. 场景图片序列（scene_01.png 到 scene_06.png）
4. 视频素材（sky_timelapse.mp4、sunset_timelapse.mp4）

要求：
- 视频分辨率：1920x1080（横版 16:9）
- 背景音乐音量降低到 30%（不要盖住旁白）
- 每张图片显示时长根据脚本中的时间分配
- 视频开头加 2 秒淡入，结尾加 2 秒淡出
- 在关键位置添加文字标题（用 drawtext 滤镜）
- 输出为 final_video.mp4
```

### 5.2 常见问题排查

剪辑过程中可能会遇到问题，以下是常见问答：

**Q：FFmpeg 在哪安装？**
```bash
# Windows：下载 ffmpeg.exe 放到项目文件夹
# Mac：brew install ffmpeg
# 让 Codex 帮你检查是否已安装
```

**Q：合成后发现音画不同步怎么办？**
```bash
# 让 Codex 检查并调整
视频合成后音画不同步，旁白比画面慢了约 1 秒。请帮我调整 FFmpeg 命令修正这个问题。
```

## 6. 第五步：发布准备

### 6.1 生成标题和描述

一个好的标题决定视频的点击量：

```bash
我的视频是关于"为什么天空是蓝色的"的科普短视频，时长约 3 分钟。
请帮我生成：
1. 5 个吸引人的视频标题（适合 B站/抖音）
2. 一条视频简介（100 字以内）
3. 5-8 个相关标签
```

### 6.2 制作封面图

```bash
请帮我设计视频封面图，要求：
1. 尺寸：1920x1080
2. 包含大字标题"天空为什么是蓝色的？"
3. 包含"3分钟看懂"这样的卖点小字
4. 背景：蓝色渐变 + 大气散射效果
5. 风格：适合科普类短视频封面
```

## 小结

| 要点 | 说明 |
|------|------|
| 视频制作流程 | 选题 → 脚本 → 素材 → 配音 → 剪辑 → 发布，6 个环节 AI 都能帮忙 |
| 脚本是灵魂 | 好的脚本 = 好选题 + 清晰分镜 + 生动语言，用表格格式输出分镜 |
| 素材来源 | AI 绘图生成 + 免费图库搜索，两条腿走路 |
| AI 配音 | 文字转语音免去录音烦恼，注意语速和情感 |
| FFmpeg 合成 | Codex 生成命令帮你自动合成，不用学复杂剪辑软件 |
| 发布优化 | 好的标题、封面、标签决定视频的传播效果 |
