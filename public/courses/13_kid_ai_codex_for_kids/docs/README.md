# 奔向明天 — 少年 Codex 专题训练营

> 7 节课让青少年掌握 AI 编程助手 Codex，独立完成作品集。

## 课程简介

「奔向明天 — 少年 Codex 专题训练营」是一门面向 10-16 岁青少年的 AI 工具实战课。课程以 Codex CLI 为核心工具，带领学生从零开始，逐步掌握与 AI 对话完成创意作品的能力。

每节课围绕一个真实作品展开：从认识 Codex 搭建第一个作品主页，到用 AI 生成短视频、整理学习资料包、搭建自动化工作流，再到制作有观点的口播视频，最后将所有作品整合成一个完整的个人作品集网页。

## 技术栈

- **Node.js 18+**
- **Codex CLI**（AI 编程助手）
- **HTML / CSS / JavaScript**（作品网页）
- **FFmpeg**（视频处理）
- **GitHub Pages**（免费部署）

## 课程特色

- 🎯 **作品驱动**：每节课产出一个真实作品
- 🤖 **AI 实操**：全程使用 Codex CLI
- 🎤 **表达力培养**：结构化提示词训练
- 👥 **小班指导**：1 对 5 小班
- 🏆 **参赛陪跑**：1 次线上竞赛全程指导

## 快速开始

```bash
# 安装 Codex CLI
npm install -g @anthropic-ai/codex

# 启动 Codex
codex
```
