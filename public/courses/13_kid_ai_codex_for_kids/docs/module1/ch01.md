# Ch01：作品主页 — 搭建个人网页

## 学习目标

学完本章后，你将能够：

- 用结构化提示词与 Codex 高效对话
- 让 Codex 生成一个完整的 HTML 个人主页
- 在浏览器中预览和调试网页
- 将网页部署到 GitHub Pages，获得在线地址

---

## 📖 故事时间：小明想要一个"门面"

> 大明（小明的表哥）说："参加创客大赛，你得先有个自己的'门面'——就是你的个人主页。评委打开你的链接，第一眼就看到你是谁、你会什么。"
>
> 小明挠挠头："网页？那不是程序员才会做的吗？"
>
> 大明笑了："你忘了？你有 Codex 啊！跟它说清楚你想要什么，它帮你写。"
>
> 小明打开终端，启动 Codex，深吸一口气……

---

## 🔧 Step-by-Step 实操

### Step 1：启动 Codex，学会结构化提示词

> 🎬 **场景**：小明已经安装好 Codex（Ch00 完成），现在打开终端进入 `my-codex-workspace` 文件夹，输入 `codex` 启动。

与 Codex 对话的秘诀：**说得越清楚，做得越漂亮**。

小明学到的提示词公式：

```
【角色】+【任务】+【要求】+【格式】
```

**❌ 小明的第一次尝试（不好）**：
```
帮我做个网页
```
→ Codex 回了一句："你想要什么样的网页？什么内容？什么颜色？"

**✅ 小明的第二次尝试（好多了）**：
```
【角色】你是一个网页设计师
【任务】帮我做一个个人介绍网页
【要求】背景用蓝色渐变，要有我的名字、爱好和一张图片的位置
【格式】输出完整的 HTML 文件代码
```

> 🎯 **本节核心技能**：结构化提示词 = 角色 + 任务 + 要求 + 格式。

### Step 2：明确目标——小明想要什么？

> 🎬 **场景**：小明想要一个简洁的个人主页，包含自我介绍和作品展示区。他打开 Codex 对话框，开始描述需求。

小明想要的网页包含：
- 你的名字和一句话自我介绍
- 你的兴趣爱好列表
- 一个"我的作品"展示区（先留空，后面慢慢填）
- 好看的颜色和排版

### Step 3：编写提示词——小明这样告诉 Codex

小明在 Codex 对话框中输入：

```
我想做一个个人作品主页网页，具体要求如下：

1. 网页标题是"【你的名字】的作品集"
2. 顶部有一个大标题和一句话自我介绍
3. 中间列出我的兴趣爱好（编程、画画、打篮球）
4. 下方有一个"我的作品"区域，里面有3个空白卡片位置
5. 颜色风格：蓝色系，简洁大方
6. 输出完整的 HTML 文件，包含内嵌的 CSS 样式

请生成完整的 index.html 代码。
```

### Step 5：保存并预览——见证奇迹！

小明让 Codex 保存文件：

```bash
请帮我把上面的 HTML 代码保存为 index.html 文件
```

保存后，小明双击 `index.html`，浏览器打开了一个漂亮的蓝色渐变网页！

> 🎉 **小明的反应**："哇！真的有！这是我做的网页！"——这是小明人生中第一个靠自己（借助 AI）做出来的网页。

### Step 6：调试与迭代——第一次不一定完美

网页有个地方小明不太满意——标题颜色不够醒目。他继续跟 Codex 说：

```bash
# 例如调整颜色
我想把背景换成更亮一点的蓝色，你能帮我修改吗？

# 或者添加新内容
我想在页面底部加一个联系方式，包含我的邮箱
```

> 🔧 **调试心态**：AI 不会每次都一次做对。**修改 → 预览 → 再修改**，这是正常的创作流程。你正在学习如何与 AI 迭代协作！

## 5. 把网页发布到互联网 —— 让全世界看到

### Step 7：为什么需要发布？

> 🎬 **场景**：小明开心地看着自己的网页，然后问大明："可是……这个网页只有我电脑上能看到，评委怎么看啊？"
>
> 大明："好问题！你需要把它部署到互联网上。GitHub Pages 可以免费帮你做到！"

### Step 8：用 GitHub Pages 部署

### 部署步骤

```bash
# 让 Codex 帮你初始化 Git 仓库
帮我把当前项目文件夹初始化为一个 Git 仓库，并推送到 GitHub

# Codex 会引导你完成：
# 1. git init（初始化仓库）
# 2. git add .（添加所有文件）
# 3. git commit -m "我的第一个作品主页"（提交）
# 4. 在 GitHub 上创建仓库并推送
```

**步骤 1**：让 Codex 初始化 Git 仓库

在 Codex 中继续：
```bash
请帮我启用 GitHub Pages，使用 main 分支作为发布源
```

**步骤 2**：启用 GitHub Pages

几分钟后，你的网站就会在 `https://你的用户名.github.io/仓库名/` 上线！

> 🎉 **恭喜！你现在是一个有自己网站的开发者了！**

## 👐 动手试试

### 基础挑战 ⭐

1. 修改网页中的名字和爱好，换成你自己的信息
2. 调整网页的背景色，试试你喜欢的颜色组合

### 进阶挑战 ⭐⭐

3. 在网页上添加一张你自己的照片（让 Codex 帮你写 `<img>` 标签）
4. 添加一个"关于我"栏目，用 3 句话介绍自己

### 挑战任务 ⭐⭐⭐

5. 尝试让 Codex 给你的网页添加一个**简单的动画效果**（比如标题跳动的动画）
6. 把网页分享给一个朋友，让他在手机上打开试试——检查是否在手机上也能正常显示

## 小结

| 要点 | 说明 |
|------|------|
| Codex 是什么 | 一个运行在命令行中的 AI 编程助手，用自然语言对话即可生成代码 |
| 结构化提示词 | `【角色】+【任务】+【要求】+【格式】` ——说清楚才能做得好 |
| HTML 网页生成 | 用清晰的提示词描述页面需求，Codex 生成完整代码 |
| 迭代调试 | 反复修改→预览→再修改，这是正常的创作节奏 |
| 部署上线 | GitHub Pages 可以免费把网页发布到互联网 |
