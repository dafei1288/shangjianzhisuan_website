# 一人公司（OPC）实战：用 AI Agent 打造个人企业

> **课程定位**：面向有基础编程经验的开发者，从零搭建一个由 AI Agent 团队驱动的「一人公司」
> **前置要求**：JavaScript/TypeScript 基础、命令行操作、对 AI/LLM 有基本了解
> **预计学时**：40-50 小时（含实战项目）


## 👥 这门课适合谁？

### 典型学员 A：小李 - 独立开发者
- **背景**：一个人做 SaaS 产品，但客服/运营/市场都要自己做，精力不够
- **痛点**：请不起人（成本高），外包不靠谱，想用 AI 替代人力
- **学完后**：能用 AI Agent 团队替代 3-5 个人工岗位，节省 30 万/年人力成本，专注产品核心功能

### 典型学员 B：小王 - 创业者
- **背景**：创业初期团队 ≤3 人，想快速验证 MVP，但招人成本高
- **痛点**：不知道怎么用 AI 搭建"一人公司"，不知道哪些环节能 AI 化
- **学完后**：能用 AI Agent 搭建市场部/运营部/客服部，快速验证 MVP，节省 3-6 个月招人时间

### 典型学员 C：老张 - 自由职业者
- **背景**：做咨询/设计/写作等服务，想扩大业务规模但不想雇人
- **痛点**：一个人精力有限，想接更多项目但处理不过来
- **学完后**：能用 AI Agent 自动化售前咨询/项目管理/客户跟进，业务规模扩大 3 倍

## 💼 应用场景

**工作场景**
1. **企业 AI 自动化**：给企业搭建 AI 客服/AI 销售助手，按效果收费
2. **SaaS 产品集成**：给 SaaS 产品加 AI 功能（智能客服/自动回复/数据分析）
3. **咨询服务**：给中小企业提供"AI 降本增效"咨询，按项目收费

**个人项目**
1. **一人 SaaS**：用 AI Agent 团队运营 SaaS 产品（如智能简历生成器、合同审查工具）
2. **AI 外包项目**：接"AI 客服系统""AI 营销自动化"外包，月入 2-5 万
3. **内容创业**：用 AI Agent 自动化内容生产/分发/变现（公众号/小红书/YouTube）

**技术深造**
1. **学习 AI Agent 框架**：深入理解 LangGraph/AutoGen/MetaGPT 架构
2. **研究多 Agent 协作**：设计复杂的多 Agent 系统（10+ Agent 协作）
3. **开发 Agent 工具**：开发 MCP Server 或 Agent 框架插件

## 课程简介

本课程教你用 AI Agent 技术打造一个「一人公司」（One Person Company）。通过 AI Agent 团队，一个人就能完成原来需要整个团队才能做的工作——内容营销、客服、运营、开发、数据分析。

课程采用 **AB 双轨设计**：
- **A 轨（OpenClaw）**：本地优先的 Agent 网关，偏执行层
- **B 轨（Paperclip）**：AI 劳动力控制面板，偏管理层

学员选一条路线跟到底即可，两条路线的知识点一一对应。

## 核心概念

| 概念 | 说明 |
|------|------|
| 一人公司 (OPC) | 一个人借助 AI Agent 团队，完成全链条业务 |
| Agent | 具有特定角色和能力的 AI 助手，可自主执行任务 |
| Skill | Agent 的能力单元，定义它可以做什么 |
| 记忆系统 | Agent 的短期/长期知识存储，支撑上下文理解 |
| 多 Agent 协作 | 多个 Agent 之间分工协作、编排管理 |
