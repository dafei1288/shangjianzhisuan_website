工具体系

选 Paperclip 还是 OpenClaw？

同生态位的两个顶级框架，课程两个都教。你选一个跟到底。

🏛️

Paperclip

AI 劳动力的人类控制面板
  • 可视化 Dashboard 管理 agent 团队
  • 组织架构：部门、角色、汇报关系
  • 目标体系：公司 → 部门 → 个人
  • 预算管理：token 消耗实时监控
  • 审批流：关键操作人工审核
  • 技术栈：Node.js + React
VS
⚡

OpenClaw

本地优先的 AI Agent 网关
  • Gateway 架构：50+ 消息平台对接
  • Skill 系统：灵活组合 agent 能力
  • 记忆系统：短期 + 长期记忆
  • 本地安全：沙箱执行与权限控制
  • 全模型支持：OpenAI / Claude / 本地
  • 完全本地运行，数据不出机器
