# 从0手写大语言模型 JimGPT

> 40 章实战课程，从 Tokenizer 到 Agents，手写每一行代码

## 课程简介

本课程带你从零开始，用 Python + PyTorch 手写一个完整的大语言模型（LLM）。不依赖 Transformers 库，每一个核心组件都亲手实现。

## 课程特色

- **纯手写实现** — 不依赖 Transformers 库，理解每一行代码
- **40 章循序渐进** — 从 Tokenizer 到 Agents，完整覆盖
- **每章可运行 Demo** — 即学即练，立竿见影
- **覆盖前沿技术** — MoE、Mamba、RLHF、Agents

## 学习路径

```
基础入门 → Tokenization → 嵌入层 → 注意力机制
    → Transformer Block → 完整模型 → 训练优化
    → 微调对齐 → 现代架构 → 前沿技术
```

## 快速开始

```bash
# 安装依赖
pip install torch numpy

# 运行第一章
python demos/ch01/main.py

# 运行核心章节
python demos/ch09/main.py   # Self-Attention
python demos/ch17/main.py   # GPT-2 完整架构
python demos/ch40/main.py   # JimGPT 完整实现
```
