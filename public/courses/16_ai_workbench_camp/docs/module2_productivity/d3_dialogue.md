# D3: 对话力——让 AI 写出能直接用的东西

> ⚡ Module 2 · 解放生产力 · 第 3 天 | 认知课 30 分钟 + 实战 60–90 分钟

## 学习目标

- 理解 AI 写作的真相：不是"一键生成"，而是**三步成型**——给上下文、出初稿、迭代改
- 掌握高质量提问的结构：背景 + 任务 + 要求 + 格式
- 掌握 5 句最有用的"迭代改稿话术"
- 建立自己的验收清单：什么样的稿子能直接发
- 产出 3 套专属写作模板（周报/邮件/方案）

## 认知课：AI 写作的真相

### 大多数人卡在第二步

```text
普通人的用法：              高手的用法：
提问 → 一次成稿 → 失望      提问 → 初稿 → 迭代 → 验收
   ↑                            ↑          ↑
缺上下文                有档案喂着    会"追着改"
```

**核心认知**：AI 的第一稿永远是"草坯"，价值在于迭代速度——改 3 轮只要 3 分钟，而人改 3 轮要 3 小时。

### 提问公式：背景 + 任务 + 要求 + 格式

```markdown
【背景】我是谁 + 这件事的来龙去脉（贴 D2 的"常用背景"）
【任务】要 AI 做什么，动词开头
【要求】长度、口吻、重点、禁忌
【格式】分点 / 表格 / 邮件体 / 一段话

例：
【背景】（贴上常用背景）本周完成了渠道 A 投放测试，
        数据：曝光 50 万，点击率 2.1%，转化 340 单，ROI 1.8
【任务】写一封周报正文，发给部门负责人
【要求】先结论后过程；数据必附；不超过 300 字；
        口吻参照我过往周报（附一段）
【格式】三段式：本周结论 / 关键数据 / 下周计划
```

### 5 句最有用的迭代话术

```text
1. "更口语一点，像跟同事说话"        ← 治书面腔
2. "砍掉一半，只留最有信息量的"      ← 治啰嗦
3. "换个版本：这次是给____看的"      ← 一稿多投
4. "第 2 点展开说，其他不动"          ← 精准修改
5. "不好，重来。要____的感觉"        ← 果断否决不客气
```

### 验收清单：什么样的稿子能直接发

```text
□ 事实核对：所有数字、人名、日期是你提供的，没有 AI 编的
□ 口吻一致：读起来像你写的（对照风格指南）
□ 读者视角：目标读者读完知道"结论是什么、要我做什么"
□ 长度合规：没超字数
□ 零黑话：没有"赋能""抓手""闭环"（除非你们公司真用）
```

> ⚠️ **AI 会一本正经地编造数据**——验收第一关永远是事实核对。这是人工环节不能外包的根本原因。

## 实战任务

### 任务 1：周报实战（30 分钟）

用**你本周的真实工作**走一遍完整三步：

1. **给上下文**：贴"常用背景" + 本周的关键事实（做了什么、数据是什么）
2. **出初稿**：用上面的提问公式发起
3. **迭代改**：至少用 2 句迭代话术改稿（推荐 1 + 2）
4. **验收**：过 5 条验收清单 → 达到"能直接发" ✅

### 任务 2：难写的邮件实战（20 分钟）

选一封你一直拖延没写/很难措辞的邮件（拒绝、催办、要资源、道歉均可）：

```markdown
【背景】对方是谁 + 事情的来龙去脉 + 你和对方的关系
【任务】写这封邮件
【要求】既不伤关系，又把事说清；（具体要求你自己补）
【格式】邮件体：称呼 + 正文 + 结尾

⚠️ 特别验收：这封邮件发出去，对方最可能的反应是什么？
   让 AI 预演"对方收到后的三种反应"，选择最稳的版本。
```

### 任务 3：方案初稿实战（30 分钟）

一份你手头的真实方案（项目提案、活动方案、汇报材料均可）：

```markdown
【背景】贴常用背景 + 方案的目标与约束（预算/时间/人手）
【任务】产出方案框架，含：目标 / 三个可选思路 / 推荐理由 / 风险
【要求】思路要有取舍对比，不是罗列
【格式】大纲级即可，细节我自己填
```

> 方案类任务的正确期待：AI 出**结构和选项**，判断和拍板是你的事。

### 任务 4：沉淀 3 套模板（10 分钟）

把今天验证过的三套提示词，按下面的模板格式存入 `03-素材/模板库/`：

```markdown
# [模板] 周报 - 部门
## 使用场景
## 提示词（占位符用 {{ }} 标出）
【背景】{{贴常用背景}}本周关键事实：{{事实列表}}
【任务】写周报正文，发给{{读者}}
【要求】{{长度/口吻/重点}}
【格式】三段式：本周结论 / 关键数据 / 下周计划
## 迭代话术（本模板专用）
## 验收清单
```

## 常见卡点 FAQ

**Q1：AI 写出来还是空话连篇？**
A：九成是上下文不够。检查：贴背景了吗？给数据了吗？附过你写过的真实段落吗？喂得越具体，写得越实。

**Q2：AI 把数据编错了？**
A：正常，这就是验收第一关。规则：**数字永远由你提供，AI 只负责组织语言**。发现编造立刻指出："数据只用我给的，不要自行推测。"

**Q3：改了好几轮还是不满意？**
A：不是继续改，是**换提问**。问 AI："你觉得这个任务要写好，还需要我提供什么信息？"——让它反问你，往往一轮就破局。

**Q4：模板存好了，下周怎么用？**
A：打开模板 → 替换 `{{占位符}}` → 发给 AI。你会发现每周只花 2 分钟替换事实，其余全自动。这正是 D4 要放大的事。

## 小结

| 要点 | 说明 |
|---|---|
| 三步成型 | 给上下文 → 出初稿 → 迭代改；初稿是草坯，价值在迭代速度 |
| 提问公式 | 背景 + 任务 + 要求 + 格式 |
| 迭代话术 | 口语化 / 砍一半 / 换读者版本 / 精准展开 / 果断重来 |
| 验收清单 | 事实、口吻、读者视角、长度、黑话——人工环节不外包 |
| 模板化 | 三套模板入库，下周开始只花 2 分钟 |
