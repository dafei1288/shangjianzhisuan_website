# 6 天 AI 工作台实战营

> 建第二大脑 · 解放生产力 · 打通通路——6 天亲手搭建出属于你的个人 AI 工作台。

给普通人的 AI 提效课：**无需编程基础**，图文教案 + 每日实战任务，无直播、随报随学。结营带走 6 个交付物：第二大脑、AI 认识我资料包、写作模板包、3 个 AI 助手、1 条工作流、**个人 AI 工作台 1.0**。

## 课程心智模型

```
第一步            第二步            第三步
🧠 第二大脑    →   ⚡ 解放生产力   →   🔗 打通通路
把资料经验存进去     AI 接管重复劳动     任务一个台面流转
   记得住             干得快             转得起来

        最终成果：个人 AI 工作台 1.0
```

## 适合谁

- **小李（职场人）**：被周报、邮件、纪要淹没，想让文字工作 10 分钟出活
- **王姐（自由职业者）**：一个人身兼多职，资料散落，请不起助理
- **老张（小团队负责人）**：想沉淀团队经验，摆脱"老人依赖"
