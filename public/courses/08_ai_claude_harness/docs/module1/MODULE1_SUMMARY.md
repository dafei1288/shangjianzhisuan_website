## 💡 核心概念总结

### 1. Harness 的本质
- **定义**：将 LLM 转变为可执行 Agent 的基础设施
- **职责**：工具管理、状态管理、权限控制、上下文管理
- **价值**：让 LLM 能够与真实世界交互

### 2. QueryEngine 的核心
- **消息循环**：LLM → 工具执行 → LLM → ... → 最终响应
- **状态管理**：保持会话连续性、支持回滚
- **工具调度**：并发执行、结果聚合

### 3. 工具系统的设计
- **JSON Schema**：标准化工具定义
- **生命周期**：注册 → 发现 → 调用 → 验证 → 执行
- **可扩展性**：内置工具 + MCP 工具 + 自定义工具

### 4. 上下文管理的挑战
- **Token 限制**：200K 上下文窗口
- **成本优化**：Prompt Caching 节省 50-90%
- **压缩策略**：滑动窗口、摘要、混合

### 5. 安全的重要性
- **多层防护**：权限 + 检测 + 沙箱 + 审计
- **显式授权**：危险操作需要用户确认
- **持续监控**：审计日志 + 异常检测
