# Ch14: 闭包捕获

## 学习目标
- 理解闭包的本质：函数 + 定义时的环境快照
- 掌握为什么需要闭包：函数引用外层变量的正确语义
- 理解 `JimFunction.closure` 字段的作用与实现
- 能实现并分析计数器闭包、makeAdder 等经典模式

## 核心概念

**闭包**（Closure）= 函数 + 定义时可见的变量绑定。当函数被创建时，它"捕获"了当前环境的引用；即使外层函数已经返回，被捕获的变量依然存活，因为闭包持有对该 Environment 的引用。

**为什么需要闭包**：考虑以下场景：

```
fun makeCounter() {
    var count = 0;
    fun increment() {
        count = count + 1;
        return count;
    }
    return increment;
}
var c = makeCounter();
print c(); // 1
print c(); // 2
print c(); // 3
```

`makeCounter` 返回后，其局部变量 `count` 按理应该消失。但 `increment` 闭包持有对包含 `count` 的 Environment 的引用，使其继续存活。每次调用 `c()` 都修改同一个 `count`，实现了状态封装。

**实现关键**：`JimFunction` 在**创建时**（而非调用时）保存当前 Environment 为 `closure`。调用时，新环境的 parent 指向 `closure`，而非调用点的环境。这正是词法作用域的体现。

**多个闭包共享同一环境**：同一个外层函数创建的多个内层函数，共享同一个 `closure` Environment 实例。一个闭包修改了捕获的变量，另一个闭包能看到变化。

## 关键代码

```java
// 函数定义时保存当前环境为 closure
case Stmt.Function(var name, var params, var body) -> {
    // this.env 是定义时的环境，而非调用时的环境
    JimFunction fn = new JimFunction(params, body, this.env);
    this.env.define(name, new Value.Fn(fn));
}

// 调用时：新环境的 parent 是 closure，不是当前调用环境
@Override
public Value call(Interpreter interp, List<Value> args) {
    Environment env = new Environment(closure); // ← 关键：parent = closure
    for (int i = 0; i < params.size(); i++) {
        env.define(params.get(i), args.get(i));
    }
    try {
        interp.executeBlock(body, env);
    } catch (ReturnException ret) {
        return ret.value;
    }
    return Value.NIL;
}
```

### 闭包与状态的内存模型

```
var c1 = makeCounter();
var c2 = makeCounter();

内存布局：
c1 → JimFunction(closure → Env{count:0, parent→全局})
c2 → JimFunction(closure → Env{count:0, parent→全局})

调用 c1.inc():
  新Env{parent→c1.closure} → count 查找到 c1.closure → 修改为 1
c1: Env{count:1}
c2: Env{count:0}  ← 不受影响

每次 makeCounter() 调用都创建新的 closure Env
→ 每个计数器有独立的状态
```

## 常见问题 Q&A

**Q1: 闭包和函数指针有什么区别？**

A: 函数指针只包含代码地址，没有环境信息。闭包 = 函数代码 + 捕获的环境变量。闭包让函数能"记住"定义时的上下文。

**Q2: 闭包会不会造成内存泄漏？**

A: 有可能。如果闭包捕获了大对象，且闭包被全局变量持有，大对象就无法被 GC 回收。解决方案：不用时将闭包置为 null。

**Q3: 所有语言都有闭包吗？**

A: 不。C 语言只有函数指针（无闭包）。Java 8+ 的 lambda 是有限闭包（只能捕获 final 变量）。JavaScript/Python/Scheme 是完整闭包。
