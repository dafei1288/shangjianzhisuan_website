# Ch13: 函数对象与调用

## 学习目标
- 理解函数作为一等公民的含义与实现方式
- 掌握 `JimFunction` 的数据结构设计
- 实现完整的函数调用流程：创建环境、绑定参数、执行函数体
- 理解用异常传递返回值的 Return 信号机制

## 核心概念

**函数是一等公民**：函数可以赋值给变量、作为参数传递、从其他函数返回、存入数据结构。实现上，函数是一种特殊的 `Value`，通过 `Value.Callable` 接口统一表示。

`Value.Callable` 接口只有一个方法：

```java
interface Callable {
    int arity();                          // 参数个数
    Value call(Interpreter interp, List<Value> args); // 执行调用
}
```

**JimFunction**：用户定义函数的实现类，封装三个要素：
1. 参数列表（`List<String> params`）
2. 函数体（`List<Stmt> body`）
3. 定义时的环境（`Environment closure`）——这是闭包的关键，下一章详细讲

**函数调用流程**：
1. 求值被调用对象，确认是 `Callable`
2. 求值所有参数表达式，得到参数值列表
3. 检查参数个数是否匹配（arity check）
4. 创建新 `Environment`，parent 指向 `closure`
5. 将参数名与参数值逐一绑定到新环境
6. 在新环境中执行函数体
7. 捕获 `ReturnException`，取出返回值；若无 return，返回 `nil`

**Return 信号**：`return` 语句需要跨越多层 `execute` 调用直接返回到函数调用点。用一个不填充栈帧的轻量异常（`ReturnException`）携带返回值，在 `JimFunction.call` 处捕获。

## 关键代码

```java
// Value 体系中加入 Callable
sealed interface Value permits Value.Num, Value.Str, Value.Bool, Value.Nil, Value.Fn {}

record Value.Fn(JimFunction fn) implements Value {}

// JimFunction 实现
class JimFunction implements Value.Callable {
    private final List<String> params;
    private final List<Stmt>   body;
    final Environment          closure; // 定义时的环境

    JimFunction(List<String> params, List<Stmt> body, Environment closure) {
        this.params  = params;
        this.body    = body;
        this.closure = closure;
    }

    @Override
    public int arity() { return params.size(); }

    @Override
    public Value call(Interpreter interp, List<Value> args) {
        // 1. 创建函数执行环境，parent 为 closure
        Environment env = new Environment(closure);
        // 2. 绑定参数
        for (int i = 0; i < params.size(); i++) {
            env.define(params.get(i), args.get(i));
        }
        // 3. 执行函数体，捕获 return 信号
        try {
            interp.executeBlock(body, env);
        } catch (ReturnException ret) {
            return ret.value;
        }
        return Value.NIL; // 无 return 语句，返回 nil
    }
}

// Interpreter 中处理函数调用表达式
case Expr.Call(var callee, var argExprs) -> {
    Value calleeVal = evaluate(callee);
    if (!(calleeVal instanceof Value.Fn(var fn))) {
        throw new RuntimeError("只有函数可以被调用");
    }
    List<Value> args = argExprs.stream().map(this::evaluate).toList();
    if (args.size() != fn.arity()) {
        throw new RuntimeError("参数个数不匹配: 期望 " + fn.arity() + "，实际 " + args.size());
    }
    yield fn.call(this, args);
}
```

### 函数调用的完整执行追踪

```
fun add(a, b) { return a + b; }
var result = add(3, 4);

1. 解释器遇到 fun 声明
   → 创建 JimFunction(params=[a,b], body=[return a+b], closure=全局env)
   → 全局 env: {add: JimFunction}

2. 遇到 add(3, 4)
   → evaluate(add) → JimFunction
   → arity check: 2 params, 2 args ✅
   → 创建新 env: {a:3, b:4}, parent → closure(全局)
   → execute(body, 新env)
     → evaluate(a + b)
       → get(a) = 3, get(b) = 4
       → 3 + 4 = 7
     → return 7 → throw ReturnException(7)
   → catch ReturnException → 返回 Value.Num(7)
   → var result = 7
```

## 常见问题 Q&A

**Q1: 为什么用异常实现 return？**

A: return 需要跨越多层嵌套的 `execute` 调用。Java 异常的栈展开机制天然支持这种"非本地跳转"。关键是用 `super(null, null, true, false)` 禁用栈帧填充，提高性能。

**Q2: 为什么参数个数必须严格匹配？**

A: JimLang 选择严格匹配以避免歧义。JavaScript 允许参数不匹配，但常引发 bug。Python 有默认参数值，但增加了实现复杂度。

**Q3: 内置函数和用户函数有什么区别？**

A: 都实现 `Callable` 接口。内置函数（如 `clock()`）用 Java 代码实现 `call()`，用户函数用 JimLang AST 实现。调用者无需区分。

## 小结

| 要点 | 说明 |
|------|------|
| Callable 接口 | 统一用户函数和内置函数的调用方式 |
| JimFunction | 参数列表 + 函数体 + 定义时环境 |
| 调用流程 | arity check → 创建环境 → 绑定参数 → 执行 → 捕获 return |
| ReturnException | 轻量异常，实现跨层返回 |
| 一等公民 | 函数可赋值、传参、返回 |
