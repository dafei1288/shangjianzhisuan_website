# Ch03: Token 体系与手写 Lexer

## 学习目标
- 理解 Token 的四要素：类型、词素、字面量、行号
- 设计完整的 TokenType 枚举体系
- 手写 Lexer，实现字符流到 Token 流的转换
- 掌握关键字识别、数字扫描、字符串扫描的实现技巧

## 核心概念

**Token 是词法分析的基本单元**。源码对 Lexer 来说只是一串字符，Lexer 的任务是识别出有意义的词法单元。每个 Token 携带四个信息：`type`（词法类型，如 NUMBER、PLUS）、`lexeme`（原始字符串，如 `"42"`、`"+"`）、`literal`（解析后的值，如 `42.0`、`null`）、`line`（行号，用于错误报告）。

**TokenType 枚举**按功能分为四组：单字符符号（`+`、`-`、`(`）、双字符符号（`!=`、`==`、`<=`）、字面量（NUMBER、STRING、IDENTIFIER）、关键字（`var`、`if`、`while`、`fun`、`class`）。

**手写 Lexer 的核心逻辑**是一个大循环：从当前位置读取字符，根据字符类型分支处理，生成对应 Token，推进位置指针。关键技巧是**前瞻（peek）**：在不消耗字符的情况下查看下一个字符，用于区分 `=` 和 `==`、`!` 和 `!=` 等情况。

扫描 `var x = 1 + 2;` 的过程：读到 `v` → 识别标识符 `var` → 查关键字表 → 生成 `Token(VAR, "var", null, 1)`；读到空格 → 跳过；读到 `x` → 识别标识符 → 生成 `Token(IDENTIFIER, "x", null, 1)`；以此类推。

## 关键代码

```java
// Token 数据类
public record Token(TokenType type, String lexeme, Object literal, int line) {
    @Override
    public String toString() {
        return type + " " + lexeme + " " + literal;
    }
}

// TokenType 枚举（部分）
public enum TokenType {
    // 单字符符号
    LEFT_PAREN, RIGHT_PAREN, LEFT_BRACE, RIGHT_BRACE,
    COMMA, DOT, MINUS, PLUS, SEMICOLON, SLASH, STAR,
    // 双字符符号
    BANG, BANG_EQUAL, EQUAL, EQUAL_EQUAL,
    GREATER, GREATER_EQUAL, LESS, LESS_EQUAL,
    // 字面量
    IDENTIFIER, STRING, NUMBER,
    // 关键字
    AND, CLASS, ELSE, FALSE, FUN, FOR, IF, NIL, OR,
    PRINT, RETURN, SUPER, THIS, TRUE, VAR, WHILE,
    // 结束标记
    EOF
}
```

```java
// 手写 Lexer 核心实现
public class Lexer {
    private final String source;
    private final List<Token> tokens = new ArrayList<>();
    private int start = 0;   // 当前 Token 的起始位置
    private int current = 0; // 当前扫描位置
    private int line = 1;    // 当前行号

    // 关键字表
    private static final Map<String, TokenType> KEYWORDS = Map.ofEntries(
        Map.entry("var",    TokenType.VAR),
        Map.entry("fun",    TokenType.FUN),
        Map.entry("if",     TokenType.IF),
        Map.entry("else",   TokenType.ELSE),
        Map.entry("while",  TokenType.WHILE),
        Map.entry("for",    TokenType.FOR),
        Map.entry("return", TokenType.RETURN),
        Map.entry("true",   TokenType.TRUE),
        Map.entry("false",  TokenType.FALSE),
        Map.entry("nil",    TokenType.NIL),
        Map.entry("print",  TokenType.PRINT),
        Map.entry("class",  TokenType.CLASS)
    );

    public List<Token> scanTokens() {
        while (!isAtEnd()) {
            start = current;
            scanToken();
        }
        tokens.add(new Token(TokenType.EOF, "", null, line));
        return tokens;
    }

    private void scanToken() {
        char c = advance();
        switch (c) {
            case '(' -> addToken(TokenType.LEFT_PAREN);
            case ')' -> addToken(TokenType.RIGHT_PAREN);
            case '+' -> addToken(TokenType.PLUS);
            case '-' -> addToken(TokenType.MINUS);
            case '*' -> addToken(TokenType.STAR);
            case ';' -> addToken(TokenType.SEMICOLON);
            // 双字符：需要前瞻
            case '!' -> addToken(match('=') ? TokenType.BANG_EQUAL  : TokenType.BANG);
            case '=' -> addToken(match('=') ? TokenType.EQUAL_EQUAL : TokenType.EQUAL);
            case '<' -> addToken(match('=') ? TokenType.LESS_EQUAL  : TokenType.LESS);
            case '>' -> addToken(match('=') ? TokenType.GREATER_EQUAL : TokenType.GREATER);
            // 注释：// 开头，跳过整行
            case '/' -> {
                if (match('/')) { while (peek() != '\n' && !isAtEnd()) advance(); }
                else addToken(TokenType.SLASH);
            }
            // 跳过空白
            case ' ', '\r', '\t' -> {}
            case '\n' -> line++;
            // 字符串字面量
            case '"' -> scanString();
            default -> {
                if (isDigit(c))      scanNumber();
                else if (isAlpha(c)) scanIdentifier();
                else error(line, "Unexpected character: " + c);
            }
        }
    }

    private void scanString() {
        while (peek() != '"' && !isAtEnd()) {
            if (peek() == '\n') line++;
            advance();
        }
        if (isAtEnd()) { error(line, "Unterminated string."); return; }
        advance(); // 消耗闭合的 "
        // 去掉两端引号，得到字符串值
        String value = source.substring(start + 1, current - 1);
        addToken(TokenType.STRING, value);
    }

    private void scanNumber() {
        while (isDigit(peek())) advance();
        if (peek() == '.' && isDigit(peekNext())) {
            advance(); // 消耗 '.'
            while (isDigit(peek())) advance();
        }
        addToken(TokenType.NUMBER, Double.parseDouble(source.substring(start, current)));
    }

    private void scanIdentifier() {
        while (isAlphaNumeric(peek())) advance();
        String text = source.substring(start, current);
        // 查关键字表，未找到则为普通标识符
        TokenType type = KEYWORDS.getOrDefault(text, TokenType.IDENTIFIER);
        addToken(type);
    }

    // 前瞻：查看当前字符但不消耗
    private char peek()     { return isAtEnd() ? '\0' : source.charAt(current); }
    private char peekNext() { return (current + 1 >= source.length()) ? '\0' : source.charAt(current + 1); }

    // 条件消耗：匹配则前进
    private boolean match(char expected) {
        if (isAtEnd() || source.charAt(current) != expected) return false;
        current++;
        return true;
    }

    private char advance()  { return source.charAt(current++); }
    private boolean isAtEnd() { return current >= source.length(); }
    private void addToken(TokenType type) { addToken(type, null); }
    private void addToken(TokenType type, Object literal) {
        tokens.add(new Token(type, source.substring(start, current), literal, line));
    }
}
```

## 常见问题 Q&A

**Q1: 为什么用有限状态机而不是正则表达式？**

A: 两者等价。正则表达式内部也是状态机。手写状态机更灵活，可以加入上下文判断（如区分 `//` 注释和 `/` 除法）。

**Q2: peek 需要前瞻多少个字符？**

A: JimLang 最多前瞻 1 个字符（区分 `/` 和 `//`、`!=` 和 `!`）。C 语言需要 3 个字符以上（如 `<<=`）。前瞻越少，Lexer 越快。

**Q3: 为什么不直接跳过注释？**

A: 注释可能包含有价值的信息（文档注释）。有些语言把注释存入 HIDDEN channel，后续工具（文档生成器、IDE）可以读取。

## 小结

| 要点 | 说明 |
|------|------|
| 有限状态机 | 字符流 → Token 流的核心模型 |
| peek/match | 前瞻和条件消耗，处理多字符符号 |
| 关键字表 | 先识别标识符再查表，简洁高效 |
| 行号追踪 | 错误信息必须定位到行 |
| 错误恢复 | 遇到非法字符跳过并报告 |
