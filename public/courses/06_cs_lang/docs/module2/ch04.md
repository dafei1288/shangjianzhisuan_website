## 核心概念

### ANTLR4 是什么

**ANTLR4（ANother Tool for Language Recognition）** 是一个强大的解析器生成器。它读取 `.g4` 语法文件，自动生成 Lexer、Parser 和 Visitor/Listener 接口的 Java 代码。

```
ANTLR4 工作流程：

  JimLang.g4 语法文件
       ↓ antlr4 命令
  ┌─────────────────────────┐
  │ JimLangLexer.java       │ ← 自动生成的词法分析器
  │ JimLangParser.java      │ ← 自动生成的语法分析器
  │ JimLangBaseVisitor.java │ ← Visitor 基类
  │ JimLangListener.java    │ ← Listener 接口
  └─────────────────────────┘

优势：声明式 → 不用写代码，只需描述规则
劣势：生成代码较重，调试困难
```

### .g4 语法文件结构

```
grammar JimLang;           ← 文法名（必须与文件名一致）

// ========== Lexer 规则（大写开头）==========
// 定义 Token 类型

VAR     : 'var';           ← 关键字
NUMBER  : [0-9]+;          ← 数字
IDENTIFIER: [a-zA-Z_]+;   ← 标识符
WS      : [ \t\r\n]+ -> skip;  ← 跳过空白

// ========== Parser 规则（小写开头）==========
// 定义语法结构（下一章）

program: statement* EOF;
```

### Lexer 规则语法

```
规则格式：TOKEN_NAME: pattern;

正则表达式语法：
  [0-9]      → 数字范围
  [a-zA-Z_]  → 字母或下划线
  +          → 一次或多次
  *          → 零次或多次
  ?          → 零次或一次
  |          → 或
  ()         → 分组
  'text'     → 字面量
  ~[\r\n]    → 排除（除 \r\n 外的任何字符）

特殊指令：
  -> skip           → 跳过（如空白、注释）
  -> channel(HIDDEN)→ 隐藏但保留
  -> type(TOKEN)    → 改变 Token 类型

规则顺序 = 匹配优先级：
  关键字（VAR, IF...）必须放在 IDENTIFIER 之前
  双字符符号（!=）必须放在单字符（!）之前
```

### 关键词 vs 标识符的优先级

```
输入: "var"
ANTLR4 匹配过程：
  1. 尝试 VAR: 'var' → 匹配 ✅
  2. 不再尝试 IDENTIFIER

如果 IDENTIFIER 在 VAR 前面：
  1. 尝试 IDENTIFIER: [a-zA-Z_]+ → 匹配 "var" ✅
  2. VAR 永远不会被匹配！

所以规则顺序至关重要：关键字 → 标识符
同理：!= 必须在 ! 之前，>= 必须在 > 之前
```

## 关键代码

### 完整 Lexer 规则

```antlr
// JimLang.g4 - Lexer 规则部分
grammar JimLang;

// ── 关键字（必须放在 IDENTIFIER 之前）──
VAR     : 'var';
FUN     : 'fun';
IF      : 'if';
ELSE    : 'else';
WHILE   : 'while';
FOR     : 'for';
RETURN  : 'return';
PRINT   : 'print';
CLASS   : 'class';
TRUE    : 'true';
FALSE   : 'false';
NIL     : 'nil';

// ── 标识符 ──
IDENTIFIER: [a-zA-Z_][a-zA-Z0-9_]*;

// ── 数字字面量 ──
NUMBER: [0-9]+ ('.' [0-9]+)?;

// ── 字符串字面量 ──
STRING: '"' ( '\\' . | ~[\\"\r\n] )* '"';

// ── 双字符符号（必须在单字符之前）──
BANG_EQUAL   : '!=';
EQUAL_EQUAL  : '==';
GREATER_EQUAL: '>=';
LESS_EQUAL   : '<=';

// ── 单字符符号 ──
LPAREN   : '(';   RPAREN   : ')';
LBRACE   : '{';   RBRACE   : '}';
COMMA    : ',';   DOT      : '.';
MINUS    : '-';   PLUS     : '+';
SLASH    : '/';   STAR     : '*';
SEMICOLON: ';';
BANG     : '!';   EQUAL    : '=';
GREATER  : '>';   LESS     : '<';

// ── 注释与空白 ──
COMMENT: '//' ~[\r\n]* -> skip;
WS: [ \t\r\n]+ -> skip;
```

### Java 使用代码

```java
import org.antlr.v4.runtime.*;

public class LexerDemo {
    public static void main(String[] args) {
        String source = "var x = 1 + 2 * 3;";

        // 创建字符流和 Lexer
        CharStream input = CharStreams.fromString(source);
        JimLangLexer lexer = new JimLangLexer(input);

        // 获取 Token 流
        CommonTokenStream tokens = new CommonTokenStream(lexer);
        tokens.fill();

        // 打印所有 Token
        for (Token token : tokens.getTokens()) {
            String name = JimLangLexer.VOCABULARY
                .getSymbolicName(token.getType());
            System.out.printf("%-15s '%s'%n", name, token.getText());
        }
    }
}

// 输出：
// VAR             'var'
// IDENTIFIER      'x'
// EQUAL           '='
// NUMBER          '1'
// PLUS            '+'
// NUMBER          '2'
// STAR            '*'
// NUMBER          '3'
// SEMICOLON       ';'
// EOF             '<EOF>'
```

## 手写 vs ANTLR4 对比

| 维度 | 手写 Lexer | ANTLR4 Lexer |
|------|-----------|-------------|
| 代码行数 | ~200 行 | ~30 行规则 |
| 可读性 | 命令式，需理解 switch 逻辑 | 声明式，规则即文档 |
| 扩展性 | 修改 switch，容易出错 | 添加规则即可 |
| 调试 | 容易（直接看代码） | 较难（看生成代码） |
| 性能 | 更快（无框架开销） | 稍慢（可接受） |
| 学习曲线 | 低（只需 Java） | 中（需学 ANTLR4 语法） |

## 常见问题 Q&A

**Q1: 为什么选 ANTLR4 而不是其他工具？**

A: ANTLR4 是 Java 生态中最流行的解析器生成器。相比 JavaCC（只支持 LL），ANTLR4 支持 ALL(*) 算法，能处理更多文法。相比手写（灵活但代码量大），ANTLR4 更适合快速迭代。

**Q2: 生成代码能直接用于生产吗？**

A: 可以，但建议做一层封装。生成代码的可读性不好，且修改后重新生成会覆盖。推荐用 Visitor 模式包装。

**Q3: ANTLR4 和 LEX/YACC 有什么区别？**

A: LEX/YACC 是 C 语言时代的工具。ANTLR4 是 Java 生态的现代工具，支持 LL(*)、自动错误恢复、Visitor/Listener 双模式。

## 小结

| 要点 | 说明 |
|------|------|
| 声明式 | `.g4` 文件描述规则，ANTLR4 生成代码 |
| 规则顺序 | 关键字在标识符前，双字符在单字符前 |
| 正则语法 | `[]` 范围、`+*?` 量词、`\|` 或 |
| skip 指令 | 跳过空白和注释 |
| Maven 集成 | antlr4-maven-plugin 自动生成 |
