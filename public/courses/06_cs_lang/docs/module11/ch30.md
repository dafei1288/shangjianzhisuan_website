### JimLang 完整特性清单

**基础特性**
- 数字（整数/浮点）、字符串、布尔、nil
- 算术、比较、逻辑运算符
- 变量声明（`var`）与赋值

**控制流**
- `if / else`、`while`、`for`
- `break`、`continue`、`return`

**函数**
- 一等函数、闭包、递归
- 可变参数（`...args`）

**面向对象**
- `class` 定义、`init` 构造器
- `this` 引用、字段访问
- 单继承（`extends`）、`super` 调用

**运行时**
- 树遍历解释器
- 字节码编译器 + 栈式 VM
- 标记-清除垃圾回收
- REPL 交互环境

### 扩展方向

**模块系统**：`import` / `export` 机制，支持多文件项目，解决命名空间问题。

**并发**：基于协程（coroutine）或 Actor 模型的并发原语，参考 Go 的 goroutine 或 Erlang 的 Actor。

**FFI（外部函数接口）**：允许 JimLang 调用 Java 原生方法，或被 Java 代码调用，实现与宿主语言的互操作。

**WASM 目标**：将 JimLang 编译为 WebAssembly 字节码，在浏览器中运行。

**标准库**：文件 I/O、网络、JSON 解析、正则表达式等内置库。

## 常见问题 Q&A

**Q1: 学完这门课能找到编译器相关工作吗？**

A: 这门课建立了坚实的理论基础。工业级编译器还需要学习 SSA、寄存器分配、指令调度等高级主题。但理解了词法分析、语法分析、代码生成的核心流程后，进一步学习会顺利很多。

**Q2: 下一步应该学什么？**

A: 推荐阅读《Crafting Interpreters》后半部分（C 语言实现字节码 VM），然后尝试参与开源语言项目（如 GraalVM/Truffle、Kotlin、Groovy）。

**Q3: 如何验证自己真的理解了？**

A: 尝试不用参考代码，从零重新实现一个简化版的 JimLang。如果能在 1-2 天内完成词法分析 + 语法分析 + 解释器，说明确实掌握了。
