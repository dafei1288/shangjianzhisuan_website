## 核心概念

### REPL 是什么

**REPL** 是 Read-Eval-Print Loop 的缩写，是动态语言的标准交互方式。用户输入一行代码，解释器立即执行并打印结果，然后等待下一行输入。

```
REPL 的四个阶段：

  ┌──────┐    ┌──────┐    ┌───────┐    ┌──────┐
  │ Read │───→│ Eval │───→│ Print │───→│ Loop │───┐
  └──────┘    └──────┘    └───────┘    └──────┘   │
       ↑                                         │
       └─────────────────────────────────────────┘

Read:  读取用户输入（可能是多行）
Eval:  解析并执行代码
Print: 打印表达式的值（语句无返回值则不打印）
Loop:  回到第一步

实际交互：

  JimLang> var x = 10        ← Read + Eval + (no Print)
  JimLang> x + 5             ← Read + Eval + Print
  15
  JimLang> fun double(x) {   ← Read (未闭合)
  ......>   return x * 2;    ← Read (未闭合)
  ......> }                  ← Read (闭合) + Eval + (no Print)
  JimLang> double(21)        ← Read + Eval + Print
  42
```

### 多行输入处理

```
多行检测是 REPL 的核心难点：

输入: if (x > 0) {
分析: { 未闭合 → 继续读取

输入:   print(x);
分析: 仍在 { 内 → 继续读取

输入: }
分析: 所有括号闭合 → 执行

检测方法：
  1. 括号计数法（简单可靠）
     { } depth = 0 → 完整
     ( ) depth = 0 → 完整
     [ ] depth = 0 → 完整

  2. 尝试解析法（更精确）
     尝试 parse(input)
     如果报"unexpected EOF" → 不完整
     如果报其他错误 → 语法错误
     如果成功 → 完整

实际项目中两种方法结合使用
```

### 错误恢复

```
REPL 中的错误处理原则：

  错误不应导致 REPL 退出！
  全局状态（变量、函数定义）应保留

JimLang> var x = 10       ✅ x = 10
JimLang> x / 0            ❌ Runtime error: Division by zero
JimLang> x                ✅ 10（x 仍然存在）
JimLang> var y =          ❌ Syntax error: Expected expression
JimLang> var y = 20       ✅ y = 20（上一行的语法错误不影响）

实现要点：
  try {
    eval(input);
  } catch (ParseError e) {
    // 不修改 interpreter 状态
    print("Syntax error: " + e.getMessage());
  } catch (RuntimeError e) {
    // 可能已经部分执行
    print("Runtime error: " + e.getMessage());
  }
  // 继续循环
```

## 关键代码

### REPL 主循环

```java
public class REPL {
    private final Interpreter interpreter = new Interpreter();
    private final LineReader reader;

    public REPL() {
        Terminal terminal = TerminalBuilder.builder().build();
        this.reader = LineReaderBuilder.builder()
            .terminal(terminal)
            .completer(new JimCompleter())    // 自动补全
            .history(new DefaultHistory())     // 命令历史
            .build();
    }

    public void run() {
        System.out.println("JimLang REPL v1.0 (type :help for commands)");
        while (true) {
            try {
                String input = readInput();
                if (input == null) break;

                // 特殊命令处理
                if (handleCommand(input.trim())) continue;

                // 评估输入
                Object result = interpreter.eval(input);

                // 只打印表达式的值
                if (result != null && !result.equals(Void.TYPE)) {
                    System.out.println(formatValue(result));
                }
            } catch (ParseError e) {
                System.err.println("Syntax error: " + e.getMessage());
            } catch (RuntimeError e) {
                System.err.println("Runtime error: " + e.getMessage());
            }
        }
    }

    private String readInput() throws IOException {
        StringBuilder input = new StringBuilder();
        String prompt = "JimLang> ";

        while (true) {
            String line = reader.readLine(prompt);
            if (line == null) return null;
            if (line.trim().equals("exit")) return null;

            input.append(line).append("\n");

            if (isComplete(input.toString())) {
                return input.toString().trim();
            }
            prompt = "......> ";
        }
    }
}
```

### 多行完整性检测

```java
private boolean isComplete(String input) {
    int braceDepth = 0;      // { }
    int parenDepth = 0;      // ( )
    int bracketDepth = 0;    // [ ]
    boolean inString = false;
    char stringDelim = 0;

    for (int i = 0; i < input.length(); i++) {
        char c = input.charAt(i);

        // 处理字符串（字符串内的括号不计数）
        if (inString) {
            if (c == stringDelim && input.charAt(i-1) != '\\') {
                inString = false;
            }
            continue;
        }
        if (c == '"' || c == '\'') {
            inString = true;
            stringDelim = c;
            continue;
        }

        switch (c) {
            case '{' -> braceDepth++;
            case '}' -> braceDepth--;
            case '(' -> parenDepth++;
            case ')' -> parenDepth--;
            case '[' -> bracketDepth++;
            case ']' -> bracketDepth--;
        }
    }

    return braceDepth == 0 && parenDepth == 0 && bracketDepth == 0;
}
```

### 特殊命令

```java
private boolean handleCommand(String input) {
    if (!input.startsWith(":")) return false;

    switch (input) {
        case ":help" -> {
            System.out.println("Commands:");
            System.out.println("  :help   - 显示帮助");
            System.out.println("  :vars   - 列出所有全局变量");
            System.out.println("  :funs   - 列出所有已定义函数");
            System.out.println("  :clear  - 清空环境");
            System.out.println("  :time   - 切换计时模式");
            System.out.println("  :exit   - 退出 REPL");
        }
        case ":vars" -> {
            for (var entry : interpreter.getGlobals().entrySet()) {
                System.out.printf("  %s = %s%n", entry.getKey(),
                    formatValue(entry.getValue()));
            }
        }
        case ":funs" -> {
            for (var entry : interpreter.getGlobals().entrySet()) {
                if (entry.getValue() instanceof JimFunction fn) {
                    System.out.printf("  %s(%s)%n", entry.getKey(),
                        String.join(", ", fn.getParams()));
                }
            }
        }
        case ":clear" -> {
            interpreter.getGlobals().clear();
            System.out.println("环境已清空");
        }
        case ":time" -> {
            interpreter.toggleTiming();
            System.out.println("计时模式: " +
                (interpreter.isTiming() ? "开" : "关"));
        }
        default -> System.out.println("未知命令: " + input);
    }
    return true;
}
```

### 自动补全

```java
public class JimCompleter implements Completer {
    private static final String[] KEYWORDS = {
        "var", "fun", "if", "else", "while", "for",
        "return", "print", "true", "false", "nil",
        "class", "this", "super", "and", "or", "not"
    };

    @Override
    public void complete(LineReader reader, ParsedLine line, List<Candidate> candidates) {
        String word = line.word();
        for (String kw : KEYWORDS) {
            if (kw.startsWith(word)) {
                candidates.add(new Candidate(kw));
            }
        }
    }
}
```

## 常见问题 Q&A

**Q1: REPL 和脚本模式有什么区别？**

A: REPL 逐行执行并立即输出，适合探索式开发。脚本模式一次性执行整个文件。REPL 保留全局状态（变量、函数定义），脚本模式每次重新开始。

**Q2: REPL 中的错误为什么不会退出？**

A: 设计选择。调试时需要反复尝试，错误后保留上下文很重要。如果每次错误都重启，用户体验很差。

**Q3: 如何在 REPL 中输入多行代码？**

A: 输入未闭合的 `{` 或 `(` 后自动进入多行模式，直到所有括号闭合才执行。
