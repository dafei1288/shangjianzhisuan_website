# Ch01: 编程语言是什么，不是什么

## 学习目标
- 理解编程语言的本质：将人类意图翻译为机器指令的桥梁
- 区分解释器与编译器的工作方式及应用场景
- 掌握代码执行的完整流程：从源码到机器执行
- 了解 JimLang 的设计目标与核心特性

## 核心概念

### 编程语言的本质

编程语言是一种**翻译系统**，将人类可读的高级指令转换为计算机能够执行的低级指令。就像人类语言需要翻译才能跨越语言障碍，编程语言也需要翻译机制来跨越"人机鸿沟"。

```
人类意图    →    编程语言    →    机器执行
"计算斐波那契"  →  fib(n){...}  →   CPU 指令序列

翻译的层次：
  高级语言 (Python, Java)
    ↓ 编译器/解释器
  字节码 / AST
    ↓ 虚拟机 / JIT
  机器码 (01101000...)
    ↓ CPU
  执行结果
```

### 解释器 vs 编译器

```
解释器（同声传译）：
  源码 → 逐行读取 → 立即执行 → 输出结果
  特点：启动快，执行慢，调试方便
  代表：Python, JavaScript, Ruby

编译器（书面翻译）：
  源码 → 全文编译 → 机器码 → 执行
  特点：启动慢（需编译），执行快
  代表：C, C++, Rust, Go

混合策略（JimLang 采用）：
  源码 → AST → 解释器直接执行（开发阶段）
  源码 → AST → 字节码 → VM 执行（生产阶段）
  代表：Java, C#, JimLang
```

### 代码执行的四个阶段

```
源码: var x = 1 + 2 * 3;

阶段 1: Lexer（词法分析）
  字符流 → Token 流
  var x = 1 + 2 * 3 ;
  ↓   ↓ ↓ ↓ ↓ ↓ ↓ ↓
  VAR IDENT(x) EQUAL NUM(1) PLUS NUM(2) STAR NUM(3) SEMI

阶段 2: Parser（语法分析）
  Token 流 → AST（抽象语法树）
       VarDecl(x)
           |
       Binary(+)
       /       \
    Num(1)   Binary(*)
             /      \
          Num(2)   Num(3)

阶段 3: Resolver（语义分析）
  检查：变量是否已定义？作用域是否正确？
  → x 是新变量，在此作用域中未定义 ✅

阶段 4: Interpreter/VM（执行）
  方式 A（树遍历）：递归遍历 AST，计算结果 = 7
  方式 B（字节码）：编译为 CONST, MUL, ADD 指令，VM 执行
```

## 关键代码

### JimLang 主入口

```java
public class JimLang {
    public static void main(String[] args) {
        if (args.length == 0) {
            runREPL();  // 交互式解释器
        } else {
            runFile(args[0]);  // 执行文件
        }
    }

    private static void runFile(String path) throws IOException {
        String source = Files.readString(Path.of(path));
        run(source);
    }

    private static void run(String source) {
        // 1. 词法分析：字符流 → Token 流
        Lexer lexer = new Lexer(source);
        List<Token> tokens = lexer.scanTokens();

        // 2. 语法分析：Token 流 → AST
        Parser parser = new Parser(tokens);
        List<Stmt> statements = parser.parse();

        // 3. 语义分析：检查作用域、变量引用
        Resolver resolver = new Resolver();
        resolver.resolve(statements);

        // 4a. 解释器执行（开发阶段）
        Interpreter interpreter = new Interpreter();
        interpreter.interpret(statements);

        // 4b. 字节码 VM 执行（生产阶段）
        // Compiler compiler = new Compiler();
        // Chunk chunk = compiler.compile(statements);
        // VM vm = new VM();
        // vm.execute(chunk);
    }
}
```

### JimLang 代码示例

```jim
// 变量与表达式
var message = "Hello, JimLang!";
print message;

// 函数与递归
fun fibonacci(n) {
    if (n <= 1) return n;
    return fibonacci(n - 1) + fibonacci(n - 2);
}
print fibonacci(10);  // 输出: 55

// 面向对象
class Animal {
    init(name) {
        this.name = name;
    }
    speak() {
        print this.name + " makes a sound";
    }
}
class Dog extends Animal {
    speak() {
        print this.name + " barks";
    }
}
var d = Dog("Rex");
d.speak();  // 输出: Rex barks
```

## 编译型 vs 解释型对比

| 语言 | 类型 | 执行方式 | 典型应用 |
|------|------|---------|----------|
| C/C++ | 编译型 | 源码 → 机器码 | 操作系统、嵌入式 |
| Rust | 编译型 | 源码 → LLVM IR → 机器码 | 系统编程 |
| Go | 编译型 | 源码 → 机器码 | 云原生、微服务 |
| Python | 解释型 | 源码 → 字节码 → PVM | 数据科学、AI |
| JavaScript | JIT | 源码 → 字节码 → V8 JIT | Web、Node.js |
| Java | 混合 | 源码 → 字节码 → JVM JIT | 企业应用 |
| **JimLang** | **混合** | **AST 解释 + 字节码 VM** | **教学** |

## 小结

| 要点 | 说明 |
|------|------|
| 本质 | 编程语言 = 翻译系统（人 → 机器）|

## 常见问题 Q&A

**Q1: 学完这门课能做什么？**

A: 理解编程语言的核心原理，能独立实现一门脚本语言。对日常编程也有帮助——理解了底层原理，写代码时的"直觉"会更准。

**Q2: 需要什么前置知识？**

A: Java 基础（类、接口、泛型）+ 基本数据结构（栈、链表、哈希表）。不需要编译原理背景。

**Q3: JimLang 能用于生产吗？**

A: 不能，它是教学语言。但学到的技术（AST、Visitor、字节码、GC）直接适用于工业项目。
