## 1. 为什么需要内置函数

解释器本身无法提供所有功能——获取系统时间、类型转换、数学运算等必须依赖宿主语言（Java）。**内置函数**就是这座桥梁。

```
用户代码               内置函数                Java 层
───────────────────────────────────────────────────────
clock()      →    NativeFunction      →   System.currentTimeMillis()
len("hello") →    NativeFunction      →   String.length()
type(42)     →    NativeFunction      →   switch(instanceof) ...
```

对用户来说，内置函数和自定义函数使用方式完全相同：`name(args)`。

## 2. NativeFunction 设计

### 2.1 统一 Callable 接口

```java
// 所有可调用对象统一接口
interface Callable {
    int arity();                              // 参数个数
    Value call(Interpreter interp, List<Value> args);  // 执行
}

// 用户定义函数：解释 AST
class JimFunction implements Callable { ... }

// 内置函数：执行 Java 代码
class NativeFunction implements Callable { ... }
```

### 2.2 NativeFunction 实现

```java
public class NativeFunction implements Value.Callable {
    private final String name;
    private final int arity;
    private final BiFunction<Interpreter, List<Value>, Value> body;

    public NativeFunction(String name, int arity,
                          BiFunction<Interpreter, List<Value>, Value> body) {
        this.name = name;
        this.arity = arity;
        this.body = body;
    }

    @Override
    public int arity() { return arity; }

    @Override
    public Value call(Interpreter interpreter, List<Value> args) {
        return body.apply(interpreter, args);
    }

    @Override
    public String toString() { return "<native fn " + name + ">"; }
}
```

核心：用 `BiFunction<Interpreter, List<Value>, Value>` 把任意 Java 逻辑包装成 Callable。

## 3. 六个内置函数实现

### 3.1 clock() — 系统时间

```java
define("clock", new NativeFunction("clock", 0, (interp, args) ->
    new Value.Num(System.currentTimeMillis() / 1000.0)));
```

用途：测量代码执行时间。

### 3.2 len() — 长度

```java
define("len", new NativeFunction("len", 1, (interp, args) -> {
    Value v = args.get(0);
    if (v instanceof Value.Str(var s)) return new Value.Num(s.length());
    if (v instanceof Value.List(var items)) return new Value.Num(items.size());
    throw new RuntimeError("len() 参数必须是字符串或列表");
}));
```

### 3.3 type() — 类型查询

```java
define("type", new NativeFunction("type", 1, (interp, args) -> {
    Value v = args.get(0);
    String t = switch (v) {
        case Value.Num _   -> "num";
        case Value.Str _   -> "str";
        case Value.Bool _  -> "bool";
        case Value.Nil _   -> "nil";
        case JimInstance i -> i.klass.name;  // 返回类名
        default            -> "callable";
    };
    return new Value.Str(t);
}));
```

### 3.4 str() / num() — 类型转换

```java
// str()：任意值 → 字符串
define("str", new NativeFunction("str", 1, (interp, args) ->
    new Value.Str(stringify(args.get(0)))));

// num()：字符串 → 数字
define("num", new NativeFunction("num", 1, (interp, args) -> {
    if (args.get(0) instanceof Value.Str(var s)) {
        try { return new Value.Num(Double.parseDouble(s)); }
        catch (NumberFormatException e) {
            throw new RuntimeError("无法转换为数字: " + s);
        }
    }
    throw new RuntimeError("num() 参数必须是字符串");
}));
```

## 4. 注册机制

```java
class Interpreter {
    private final Environment globals = new Environment(null);

    public Interpreter() {
        defineNatives();  // 在构造时注册所有内置函数
    }

    private void defineNatives() {
        define("clock", ...);
        define("len",   ...);
        define("type",  ...);
        define("str",   ...);
        define("num",   ...);
    }

    private void define(String name, Value value) {
        globals.define(name, value);
    }
}
```

所有内置函数在全局环境中定义，任何作用域都能访问。

## 5. 使用示例

```
// 测量代码执行时间
var start = clock();
var sum = 0;
for (var i = 0; i < 10000; i = i + 1) {
    sum = sum + i;
}

print "Sum: " + str(sum) + ", Time: " + str(elapsed) + "s";

// 类型查询
print type(42);        // "num"
print type("hello");   // "str"
print type(nil);       // "nil"

class Foo {}
var f = Foo();
print type(f);         // "Foo"
```

## 6. 参数校验的重要性

内置函数接收的是动态类型的 `Value`，用户可能传入任何类型：

```java
// ❌ 不安全的实现
define("len", new NativeFunction("len", 1, (interp, args) -> {
    String s = (String) args.get(0);  // 如果传入数字？ClassCastException！
    return new Value.Num(s.length());
}));

// ✅ 安全的实现
define("len", new NativeFunction("len", 1, (interp, args) -> {
    Value v = args.get(0);
    if (v instanceof Value.Str(var s)) return new Value.Num(s.length());
    throw new RuntimeError("len() 参数必须是字符串，实际传入: " + typeOf(v));
}));
```

**原则**：永远不要假设参数类型，用 pattern matching 检查并给出清晰的错误信息。

## 常见问题 Q&A

**Q1: 内置函数和普通函数在调用时有区别吗？**

A: 没有。都通过 Callable 接口的 call() 方法调用。用户无法区分内置函数和自定义函数，这是一致性的体现。

**Q2: 为什么不用单独的 namespace 放内置函数？**

A: JimLang 没有模块系统，全局命名空间最简单。实际语言中（如 Python）会放在 __builtins__ 模块中。

**Q3: 如何防止用户覆盖内置函数？**

A: 当前不做限制（和 JavaScript 一样）。可以加一个 "frozen" 标记，但动态语言通常允许覆盖。
