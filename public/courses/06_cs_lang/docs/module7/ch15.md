## 学习目标

- 理解类作为"一等公民"的 Callable 设计

## 1. 面向对象的核心：类与实例

面向对象的核心是"类"与"实例"的分离：

- **类（Class）**：模板，描述行为（方法），在编译时确定
- **实例（Instance）**：运行时对象，持有状态（字段），在运行时动态增减

```
JimClass: Person          JimInstance: p1          JimInstance: p2
┌──────────────────┐     ┌──────────────────┐     ┌──────────────────┐
│ name: "Person"   │     │ klass: Person    │     │ klass: Person    │
│ methods:         │     │ fields:          │     │ fields:          │
│   greet → fn()   │     │   name: "Alice"  │     │   name: "Bob"    │
│   init → fn(n)   │     │   age: 30        │     │   age: 25        │
└──────────────────┘     └──────────────────┘     └──────────────────┘
       ↑ 共享                      ↑ 独立                    ↑ 独立
```

关键点：方法存储在类中（所有实例共享），字段存储在实例中（每个实例独立）。

## 2. 类是一等公民

在 Jim 语言中，类也是一个值（Value），可以被赋值给变量、作为参数传递：

```
class Dog { ... }
var D = Dog;            // 类赋值给变量
var d = D("Rex");       // 通过变量调用类
print d;                // <Dog instance>
```

这意味着 `JimClass` 必须实现 `Value.Callable` 接口，使类可以像函数一样被"调用"（实例化）。

## 3. 关键代码

### 3.1 JimClass

```java
public class JimClass implements Value.Callable {
    public final String name;
    public final Map<String, JimFunction> methods;

    public JimClass(String name, Map<String, JimFunction> methods) {
        this.name = name;
        this.methods = methods;
    }

    @Override
    public int arity() {
        JimFunction init = methods.get("init");
        return init != null ? init.arity() : 0;
    }

    @Override
    public Value call(Interpreter interpreter, List<Value> args) {
        JimInstance instance = new JimInstance(this);
        // 若有 init() 构造函数，自动调用
        JimFunction init = methods.get("init");
        if (init != null) {
            init.bind(instance).call(interpreter, args);
        }
        return instance;
    }

    @Override
    public String toString() {
        return "<class " + name + ">";
    }
}
```

### 3.2 JimInstance

```java
public class JimInstance {
    public final JimClass klass;
    private final Map<String, Value> fields = new HashMap<>();

    public JimInstance(JimClass klass) {
        this.klass = klass;
    }

    public Value get(String name) {
        // 优先查找实例字段
        if (fields.containsKey(name)) return fields.get(name);
        // 其次查找类方法（并自动绑定 this）
        JimFunction method = klass.methods.get(name);
        if (method != null) return method.bind(this);
        throw new RuntimeError("未定义属性: " + name);
    }

    public void set(String name, Value value) {
        fields.put(name, value);
    }

    @Override
    public String toString() {
        return "<" + klass.name + " instance>";
    }
}
```

### 3.3 解释器处理 class 声明

```java
// 处理 class 声明
case Stmt.Class(var name, var methods) -> {
    Map<String, JimFunction> methodMap = new HashMap<>();
    for (Stmt.Function method : methods) {
        boolean isInit = method.name.lexeme.equals("init");
        JimFunction fn = new JimFunction(method, environment, isInit);
        methodMap.put(method.name.lexeme, fn);
    }
    JimClass klass = new JimClass(name.lexeme, methodMap);
    environment.define(name.lexeme, klass);
}
```

### 3.4 解释器处理属性访问

```java
// Expr.Get: 读取属性
case Expr.Get get -> {
    Value obj = evaluate(get.object);
    if (obj instanceof JimInstance instance) {
        yield instance.get(get.name.lexeme);
    }
    throw new RuntimeError("只有实例有属性");
}

// Expr.Set: 设置属性
case Expr.Set set -> {
    Value obj = evaluate(set.object);
    if (obj instanceof JimInstance instance) {
        Value value = evaluate(set.value);
        instance.set(set.name.lexeme, value);
        yield value;
    }
    throw new RuntimeError("只有实例有属性");
}
```

## 4. 执行追踪

```
class Person {
    init(name) { this.name = name; }
    greet() { print "Hello, " + this.name; }
}
var p = Person("Alice");
p.greet();
```

追踪：

```
1. 执行 class 声明
   → 创建 JimClass("Person", { init: fn, greet: fn })
   → environment.define("Person", JimClass)

2. 执行 var p = Person("Alice")
   → evaluate(Person) → JimClass
   → JimClass.call(args=["Alice"])
     → new JimInstance(Person)        // 创建空实例
     → methods.get("init") → fn
     → fn.bind(instance).call(["Alice"])  // 绑定 this 并调用
       → 执行 this.name = "Alice"
       → instance.fields = { name: "Alice" }
   → return instance
   → environment.define("p", instance)

3. 执行 p.greet()
   → evaluate(p) → JimInstance(fields={name:"Alice"})
   → instance.get("greet") → JimFunction(绑定 this=instance)
   → 调用绑定后的函数
   → 执行 print "Hello, " + this.name
   → evaluate(this) → JimInstance
   → instance.get("name") → "Alice"
   → 输出: Hello, Alice
```

## 5. 设计讨论

### 5.1 为什么字段是动态的

JimLang 的实例字段不需要在类中预先声明——`this.name = value` 直接创建字段。这与 Python、JavaScript 的设计一致，适合动态类型语言。

对比 Java（静态声明字段）：
```java
class Person {
    String name;  // 必须预先声明
}
```

动态字段的权衡：
- ✅ 灵活：运行时可以添加任意字段
- ✅ 简单：无需声明语法
- ❌ 容易拼写错误：`this.nmae = "Alice"` 不会报错

### 5.2 方法查找 vs 字段查找

```
p.greet:
  1. p.fields["greet"] → 不存在
  2. p.klass.methods["greet"] → 找到了！
  3. method.bind(p) → 返回绑定了 this 的新函数

p.name:
  1. p.fields["name"] → 找到了！"Alice"
  2. 直接返回，不查找类方法
```

如果实例字段和类方法同名，实例字段优先。可以用这个特性实现"方法覆盖"（per-instance method override）。

## 8. 常见问题 Q&A

**Q1: 为什么字段不需要声明？**

A: 动态语言的特性。字段在赋值时自动创建，类似 JavaScript。好处是灵活，坏处是拼错字段名不会报错。

**Q2: 类和实例的区别是什么？**

A: 类是蓝图（存方法），实例是产品（存字段）。多个实例共享同一个类的方法表。

**Q3: init 可以返回其他值吗？**

A: 可以写 return，但返回值被忽略，始终返回新实例。这保证了 `var p = Point(1,2)` 得到的是实例。

## 9. 小结

| 要点 | 说明 |
|------|------|
| JimClass | 持有方法表，实现 Callable |
| JimInstance | 持有字段 Map，引用所属类 |
| 查找顺序 | 实例字段优先，类方法次之 |
| 动态字段 | 赋值即创建，无需声明 |
| init | 构造器，始终返回 this |
