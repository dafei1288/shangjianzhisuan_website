# Ch17: 继承与 super

## 1. 继承的核心思想

### 1.1 为什么要继承

```
没有继承：每个类独立定义所有方法
class Dog { speak() { print "Woof"; } eat() { ... } }
class Cat { speak() { print "Meow"; } eat() { ... } }  // eat() 重复！

有继承：公共方法提升到父类
class Animal { eat() { ... } }
class Dog < Animal { speak() { print "Woof"; } }   // 自动继承 eat()
class Cat < Animal { speak() { print "Meow"; } }   // 自动继承 eat()
```

### 1.2 方法查找链

```
实例 d = Dog()
d.eat() 的查找路径：
  1. Dog.methods["eat"] → 没找到
  2. Animal.methods["eat"] → 找到了！调用它

d.speak() 的查找路径：
  1. Dog.methods["speak"] → 找到了！调用它（子类覆盖）
```

## 2. 关键代码

### 2.1 JimClass 支持继承

```java
public class JimClass implements Value.Callable {
    public final String name;
    public final JimClass superclass;
    private final Map<String, JimFunction> methods;

    public JimClass(String name, JimClass superclass,
                    Map<String, JimFunction> methods) {
        this.name = name;
        this.superclass = superclass;
        this.methods = methods;
    }

    // 方法查找链：子类 → 父类 → 祖父类...
    public JimFunction findMethod(String name) {
        if (methods.containsKey(name)) return methods.get(name);
        if (superclass != null) return superclass.findMethod(name);
        return null;
    }
}
```

### 2.2 解释器处理 class 继承

```java
@Override
public Void visitClassStmt(Stmt.Class stmt) {
    Value superclass = null;
    if (stmt.superclass != null) {
        superclass = evaluate(stmt.superclass);
        if (!(superclass instanceof JimClass))
            throw new RuntimeError("父类必须是类");
    }

    environment.define(stmt.name.lexeme, Value.NIL);

    // 为子类方法创建包含 super 的环境
    if (stmt.superclass != null) {
        environment = new Environment(environment);
        environment.define("super", superclass);
    }

    // 收集方法
    Map<String, JimFunction> methods = new HashMap<>();
    for (Stmt.Function method : stmt.methods) {
        boolean isInit = method.name.lexeme.equals("init");
        methods.put(method.name.lexeme,
                    new JimFunction(method, environment, isInit));
    }

    JimClass klass = new JimClass(stmt.name.lexeme,
                                   (JimClass) superclass, methods);

    // 恢复环境
    if (superclass != null) environment = environment.enclosing;

    environment.assign(stmt.name.lexeme, klass);
    return null;
}
```

### 2.3 super 表达式

```java
case Expr.Super e -> {
    // super 在编译期确定（静态绑定到父类）
    JimClass superclass = (JimClass) environment.get("super");
    // this 在运行期确定（动态绑定到当前实例）
    JimInstance instance = (JimInstance) environment.get("this");
    JimFunction method = superclass.findMethod(e.method.lexeme);
    if (method == null)
        throw new RuntimeError("未定义属性: " + e.method.lexeme);
    yield method.bind(instance);  // 绑定 this 但从父类方法表开始查找
}
```

## 3. 执行追踪

```
class Animal {
    init(name) { this.name = name; }
    speak()    { print this.name + " makes a sound"; }
}

class Dog < Animal {
    speak() {
        print this.name + " barks";
    }
    fetch() {
        print this.name + " fetches the ball";
    }
}

var d = Dog("Buddy");
d.speak();   // Buddy barks
d.fetch();   // Buddy fetches the ball

// d.speak() 查找链：
//   Dog.methods["speak"] → 找到！调用 Dog.speak()

// d.fetch() 查找链：
//   Dog.methods["fetch"] → 找到！

// d.name 查找链（来自 init）：
//   Animal.init() 被 Dog 继承，bind(this) 后执行
//   this.name = "Buddy" → 写入 instance.fields
```

带 super 的版本：

```
class Dog < Animal {
    speak() {
        super.speak();  // 调用 Animal.speak()
        print this.name + " barks";
    }
}

d.speak();
// 输出:
//   Buddy makes a sound    ← super.speak() 的效果
//   Buddy barks             ← Dog.speak() 自身的代码
```

super 调用追踪：
```
1. evaluate(Super("speak"))
   → environment.get("super") → Animal (JimClass)
   → environment.get("this")  → d (JimInstance)
   → Animal.findMethod("speak") → Animal.speak 函数
   → method.bind(d) → 新函数（闭包含 this=d）

2. 调用绑定后的 Animal.speak()
   → 执行 print this.name + " makes a sound"
   → this = d → d.get("name") → "Buddy"
   → 输出: Buddy makes a sound
```

## 4. super vs this 的绑定差异

| 维度 | `this` | `super` |
|------|--------|---------|
| 绑定时机 | 运行时（动态绑定） | 编译时确定父类（静态绑定） |
| 查找起点 | 当前实例的类 | 父类的方法表 |
| 含义 | "当前对象" | "当前对象的父类版本" |

**多层继承时的行为**：

```
class A { method() { print "A"; } }
class B < A { method() { super.method(); print "B"; } }
class C < B { method() { super.method(); print "C"; } }

C().method();
// super.method() in C → B.method()
// super.method() in B → A.method()
// 输出: A, B, C
```

## 6. 小结

| 要点 | 说明 |
|------|------|
| 方法查找链 | 从子类开始，沿 superclass 递归查找 |
| super | 静态绑定到父类方法表 |
| this | 始终动态绑定到当前实例 |
| super.method() | bind(this) 保证父类方法内 this 正确 |

## 常见问题 Q&A

**Q1: JimLang 为什么只支持单继承？**

A: 单继承实现简单，避免了菱形继承（Diamond Problem）。多继承需要引入 Mixin 或 Interface 等机制，复杂度大增。Java、C# 也选择了单继承路线。

**Q2: super 和 this 的绑定有什么区别？**

A: super 在类定义时静态绑定到父类方法表（编译期确定）。this 在运行时动态绑定到当前实例。super 是"去哪个类找方法"，this 是"对哪个对象操作"。

**Q3: 方法查找的效率如何？**

A: 每次调用沿继承链向上查找，最坏 O(n)。可以用内联缓存（Inline Cache）优化：第一次查找后缓存结果，后续直接使用。
