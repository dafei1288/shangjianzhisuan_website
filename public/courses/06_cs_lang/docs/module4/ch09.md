# Ch09: 语句执行器

## 学习目标
- 理解语句（Statement）与表达式（Expression）的本质区别
- 掌握 `print`、`if`、`while`、`block` 四类语句的 AST 设计
- 实现 `execute(Stmt)` 方法，能运行简单的控制流程序
- 理解语句执行的副作用模型
- 区分 statement-first vs expression-first 语言的设计取舍

---

## 1. 语句 vs 表达式

### 1.1 本质区别

| 维度 | 表达式 (Expression) | 语句 (Statement) |
|------|---------------------|------------------|
| 是否有值 | ✅ 求值后产生 Value | ❌ 不产生值 |
| 副作用 | 可选（如赋值表达式） | 主要目的 |
| 示例 | `1 + 2`, `x > 0` | `print x;`, `if (...) { }` |
| Java 返回 | `Value evaluate(Expr)` | `void execute(Stmt)` |

### 1.2 两套 AST 层次

```
Stmt（语句层）                Expr（表达式层）
├── Print(expr)              ├── Num(3.14)
├── If(cond, then, else)     ├── Binary(left, op, right)
├── While(cond, body)        ├── Unary(op, right)
├── Block([stmt, ...])       ├── Var(name)
└── Expression(expr)         └── Grouping(expr)
```

有些语言（如 Rust、Scala）几乎一切都是表达式；JimLang 采用传统的语句/表达式二分法，更易理解。

## 2. 语句 AST 设计

```java
sealed interface Stmt permits Stmt.Print, Stmt.If, Stmt.While, Stmt.Block,
                           Stmt.Expression, Stmt.Var {}

record Stmt.Print(Expr expr)                          implements Stmt {}
record Stmt.If(Expr cond, Stmt then, Stmt elseBranch) implements Stmt {}
record Stmt.While(Expr cond, Stmt body)               implements Stmt {}
record Stmt.Block(List<Stmt> stmts)                   implements Stmt {}
record Stmt.Expression(Expr expr)                     implements Stmt {}  // 表达式语句
record Stmt.Var(String name, Expr init)               implements Stmt {}  // 变量声明
```

## 3. 核心代码：execute 方法

```java
class Interpreter {
    void execute(Stmt stmt) {
        switch (stmt) {
            case Stmt.Print(var expr) -> {
                Value val = evaluate(expr);
                System.out.println(stringify(val));
            }
            case Stmt.If(var cond, var then, var elseBranch) -> {
                if (isTruthy(evaluate(cond))) execute(then);
                else if (elseBranch != null)  execute(elseBranch);
            }
            case Stmt.While(var cond, var body) -> {
                while (isTruthy(evaluate(cond))) execute(body);
            }
            case Stmt.Block(var stmts) -> {
                for (Stmt s : stmts) execute(s);
            }
            case Stmt.Expression(var expr) -> {
                evaluate(expr);  // 执行但丢弃返回值
            }
            case Stmt.Var(var name, var init) -> {
                Value value = (init != null) ? evaluate(init) : Value.NIL;
                environment.define(name, value);
            }
        }
    }
```

## 4. 真值判断（Truthiness）

**JimLang 规则**：`nil` 和 `false` 为假，其余一切为真。

```java
    private boolean isTruthy(Value val) {
        return switch (val) {
            case Value.Nil()       -> false;
            case Value.Bool(var b) -> b;
            default                -> true;  // 0、"" 都是 truthy
        };
    }
```

与其他语言对比：

| 值 | JimLang | Python | JavaScript | Ruby |
|----|---------|--------|------------|------|
| `0` | true ✅ | false | false | true ✅ |
| `""` | true ✅ | false | false | true ✅ |
| `nil/null/None` | false | false | false | false |
| `false` | false | false | false | false |

JimLang 采用 Ruby/Lua 风格：只有 `nil` 和 `false` 是 falsy。这样最简单，不会出现 `0` 是 falsy 导致的意外 Bug。

## 5. 手动构造 AST 示例

### 5.1 print 语句

```java
// 对应源码: print 1 + 2;
Stmt program = new Stmt.Print(
    new Expr.Binary(new Expr.Num(1), "+", new Expr.Num(2))
);
// 执行后输出: 3
```

### 5.2 if-else 语句

```java
// 对应源码: if (x > 0) print "positive"; else print "non-positive";
Stmt program = new Stmt.If(
    new Expr.Binary(new Expr.Var("x"), ">", new Expr.Num(0)),
    new Stmt.Print(new Expr.Str("positive")),
    new Stmt.Print(new Expr.Str("non-positive"))
);
```

### 5.3 while 循环

```java
// 对应源码:
// var i = 0;
// while (i < 5) { print i; i = i + 1; }
// （此处简化表示）

Stmt loop = new Stmt.While(
    new Expr.Binary(new Expr.Var("i"), "<", new Expr.Num(5)),
    new Stmt.Block(List.of(
        new Stmt.Print(new Expr.Var("i")),
        new Stmt.Expression(new Expr.Assign("i",
            new Expr.Binary(new Expr.Var("i"), "+", new Expr.Num(1))))
    ))
);
// 执行后输出: 0, 1, 2, 3, 4
```

## 6. 执行追踪

```
源码: if (true) print "yes"; else print "no";

AST:
  If(
    cond = Bool(true),
    then = Print(Str("yes")),
    else = Print(Str("no"))
  )

执行:
  execute(If(...))
    → evaluate(Bool(true)) → Value.Bool(true)
    → isTruthy(Bool(true)) → true
    → execute(Print(Str("yes")))
      → evaluate(Str("yes")) → Value.Str("yes")
      → println("yes")     ← 副作用：打印到控制台
```

## 9. 常见问题 Q&A

**Q1: 为什么 print 是语句不是函数？**

A: 作为语句更简单，不需要函数调用机制。许多教学语言（Lox、Wren）都将 print 作为语句。Python 3 把它改成了函数。

**Q2: 为什么 0 不是 falsy？**

A: JimLang 选择只有 nil 和 false 是 falsy，与 Lua 一致。让 0 也 falsy（如 JavaScript/C）容易引入 bug（如 `if (count)` 当 count 为 0 时跳过）。

**Q3: 表达式语句有什么用？**

A: 允许在语句位置使用表达式，如 `a = 1;`（赋值是表达式）或 `fib(10);`（函数调用是表达式但返回值被丢弃）。

## 10. 小结

| 要点 | 说明 |
|------|------|
| execute vs evaluate | 语句不返回值，表达式返回 Value |
| sealed interface | 保证所有语句类型都被处理 |
| isTruthy | 只有 nil 和 false 为 falsy |
| 表达式语句 | 允许在语句位置使用表达式 |
| Print | 内置语句，不作为函数 |
