## 核心概念

**块作用域**：每进入一个 `Block`，创建一个新的 `Environment`，其父指针指向当前环境；退出块时恢复父环境。变量查找从当前环境沿父链向上，直到找到或抛出"未定义变量"错误。

**变量遮蔽**：内层块可以声明与外层同名的变量，内层查找时优先命中内层定义，外层变量被"遮蔽"但不被销毁。

**for 脱糖**：`for (init; cond; incr) body` 在 Parser 阶段直接转换为等价的 `while` 结构，解释器无需新增 `for` 分支，降低复杂度。

```
for (var i = 0; i < 10; i = i + 1) { ... }
// 脱糖为：
{
  var i = 0;
  while (i < 10) {
    { ... }
    i = i + 1;
  }
}
```

**Return 信号**：`return` 语句需要跨越多层 `execute` 调用栈直接返回到函数调用点。Java 的异常机制天然支持这种"非本地跳转"，定义一个 `ReturnException` 携带返回值即可。

## 关键代码

```java
class Environment {
    private final Map<String, Value> values = new HashMap<>();
    private final Environment parent; // null 表示全局环境

    Environment(Environment parent) { this.parent = parent; }

    void define(String name, Value value) {
        values.put(name, value);
    }

    Value get(String name) {
        if (values.containsKey(name)) return values.get(name);
        if (parent != null) return parent.get(name);
        throw new RuntimeError("未定义变量: " + name);
    }

    void assign(String name, Value value) {
        if (values.containsKey(name)) { values.put(name, value); return; }
        if (parent != null) { parent.assign(name, value); return; }
        throw new RuntimeError("未定义变量: " + name);
    }
}

// execute 中处理 Block，保存/恢复环境
case Stmt.Block(var stmts) -> {
    Environment previous = this.env;
    this.env = new Environment(previous); // 进入新作用域
    try {
        for (Stmt s : stmts) execute(s);
    } finally {
        this.env = previous; // 无论是否异常，都恢复
    }
}

// Return 信号
class ReturnException extends RuntimeException {
    final Value value;
    ReturnException(Value value) { super(null, null, true, false); this.value = value; }
}

case Stmt.Return(var expr) ->
    throw new ReturnException(expr != null ? evaluate(expr) : Value.NIL);
```

### for 循环脱糖的 AST 对比

```
源码: for (var i = 0; i < 10; i = i + 1) print i;

生成的 AST:
Block(
  [Var("i", Num(0))],
  While(
    Binary(Var("i"), "<", Num(10)),
    Block([
      Print(Var("i")),
      Expression(Assign("i", Binary(Var("i"), "+", Num(1))))
    ])
  )
)

注意：整个 for 被包裹在一个额外的 Block 中
      → init 变量的作用域限定在循环内
```

### Environment 链操作图解

```
执行 var x = 1; { var y = 2; { print x + y; } }

全局 env: {x: 1}
  └→ Block1 env: {y: 2}, parent → 全局
       └→ Block2 env: {}, parent → Block1

查找 x + y:
  x: Block2 → Block1 → 全局 ✅
  y: Block2 → Block1 ✅

退出 Block2: env = Block1
退出 Block1: env = 全局
y 不再可访问
```

## 常见问题 Q&A

**Q1: 为什么用异常实现 return？**

A: return 需要跳过当前函数内所有待执行的语句。异常的栈展开机制正好满足这个需求。这是解释器实现中的经典技巧（也叫 "non-local exit"）。

**Q2: for 脱糖有什么好处？**

A: 解释器不需要新增 `for` 分支，减少代码量。Parser 负责转换，保持解释器简洁。这是"在编译层消化复杂性"的设计哲学。

**Q3: Environment 链的性能如何？**

A: 每次变量查找需要沿链遍历，最坏 O(n)（n = 嵌套深度）。大多数程序嵌套不超过 10 层，实际性能完全可接受。字节码 VM 中会改用栈偏移，消除这个开销。

## 小结

| 要点 | 说明 |
|------|------|
| Environment 链 | 块作用域的核心：进入 Block 创建新环境，退出恢复 |
| 变量遮蔽 | 内层同名变量覆盖外层，退出后恢复 |
| for 脱糖 | Parser 阶段转为 while + block，解释器无感知 |
| return | 用 ReturnException 实现非本地跳转 |
| finally | 保证作用域在任何情况下正确恢复 |
