## 13.1 文档解析：从格式到纯文本

### 13.1.1 多格式挑战

| 格式 | 解析难度 | 推荐工具 | 常见坑 |
|------|----------|----------|--------|
| **PDF** | 高（版面/字体/图片） | Apache PDFBox / Tika / pdf2htmlEX | 表格错乱、扫描件需 OCR |
| **Word (.docx)** | 中 | Apache POI / Tika | 公式、修订标记 |
| **Excel (.xlsx)** | 中 | Apache POI | 多 Sheet 合并、公式结果 |
| **PPT (.pptx)** | 中 | Apache POI | 演讲者备注 |
| **HTML** | 低 | Jsoup | 广告/导航噪声 |
| **Markdown** | 极低 | 直接读 | - |
| **TXT** | 极低 | 直接读 | 编码（GBK/UTF-8） |

### 13.1.2 Apache Tika：统一入口

Tika 是 Apache 旗下的「瑞士军刀」——**一个 API 解析 1000+ 格式**：

```xml
<dependency>
    <groupId>org.apache.tika</groupId>
    <artifactId>tika-core</artifactId>
    <version>2.9.2</version>
</dependency>
<dependency>
    <groupId>org.apache.tika</groupId>
    <artifactId>tika-parsers-standard-package</artifactId>
    <version>2.9.2</version>
</dependency>
```

```java
import org.apache.tika.Tika;
import org.apache.tika.metadata.Metadata;
import org.apache.tika.parser.ParseContext;
import org.apache.tika.parser.Parser;
import org.apache.tika.sax.BodyContentHandler;
import org.xml.sax.ContentHandler;

public String parse(File file) throws Exception {
    Parser parser = new AutoDetectParser();   // 自动识别格式
    ContentHandler handler = new BodyContentHandler(-1);   // -1 = 不限制大小
    Metadata metadata = new Metadata();
    parser.parse(new FileInputStream(file), handler, metadata, new ParseContext());

    // metadata 包含 title/author/created 等元信息
    System.out.println("Title: " + metadata.get(TikaCoreProperties.TITLE));
    return handler.toString();
}
```

## 13.2 分块策略：从文本到向量

### 13.2.1 为什么必须分块

**LLM 上下文有限** + **整篇嵌入精度差** + **检索粒度需要细**——三个原因叠加，分块是 RAG 的**第一性原理**。

```
原始文档（10万字）                  分块后（每块 500 字）
─────────────                       ────────────────────
[████████████████████]              [██][██][██][██][██][██]...
       ↓                                  ↓  ↓  ↓  ↓  ↓  ↓
   1 个向量（噪声多）              20 个向量（语义自洽）
   检索精度低                       检索精度高
```

### 13.2.2 分块三要素

| 要素 | 含义 | 经验值 |
|------|------|--------|
| **chunk size** | 单块大小 | 200-500 字符（中文）/ 500 token（英文） |
| **overlap** | 相邻块重叠 | chunk size 的 10-20% |
| **split by** | 切分单元 | 段落 > 句子 > 字符 |

### 13.2.3 五种分块策略

#### 策略 1：字符分块（最简单）

```java
public List<String> chunkByChar(String text, int size, int overlap) {
    List<String> chunks = new ArrayList<>();
    int step = size - overlap;
    for (int i = 0; i < text.length(); i += step) {
        chunks.add(text.substring(i, Math.min(i + size, text.length())));
        if (i + size >= text.length()) break;
    }
    return chunks;
}
```

**优点**：实现最简。
**缺点**：可能切断句子、单词。

#### 策略 2：递归分块（推荐）

按「段落 → 句子 → 字符」逐级降级，**优先在自然边界切**：

```java
public class RecursiveSplitter {
    private static final String[] SEPARATORS = {"\n\n", "\n", "。", "！", "？", ".", "!", "?", " "};

    public List<String> split(String text, int maxSize, int overlap) {
        List<String> result = new ArrayList<>();
        splitRecursive(text, maxSize, 0, result);
        return applyOverlap(result, overlap);
    }

    private void splitRecursive(String text, int maxSize, int sepIdx, List<String> out) {
        if (text.length() <= maxSize) {
            out.add(text);
            return;
        }
        if (sepIdx >= SEPARATORS.length) {
            // 降级到字符分块
            for (int i = 0; i < text.length(); i += maxSize) {
                out.add(text.substring(i, Math.min(i + maxSize, text.length())));
            }
            return;
        }
        String sep = SEPARATORS[sepIdx];
        String[] parts = text.split(Pattern.quote(sep), -1);
        StringBuilder current = new StringBuilder();
        for (String part : parts) {
            if (current.length() + part.length() + sep.length() <= maxSize) {
                if (current.length() > 0) current.append(sep);
                current.append(part);
            } else {
                if (current.length() > 0) out.add(current.toString());
                if (part.length() > maxSize) {
                    splitRecursive(part, maxSize, sepIdx + 1, out);
                } else {
                    current = new StringBuilder(part);
                }
            }
        }
        if (current.length() > 0) out.add(current.toString());
    }
}
```

**LangChain4j 内置**：`DocumentSplitters.recursive(maxSize, overlap)` 已经是这个实现。

#### 策略 3：Markdown/代码分块（结构感知）

按 H1/H2/H3 标题切，保留层级上下文：

```java
public List<String> chunkMarkdown(String md, int maxSize) {
    List<String> chunks = new ArrayList<>();
    String[] sections = md.split("(?=^#{1,3} )", -1);   // 按 markdown 标题
    for (String section : sections) {
        if (section.length() <= maxSize) {
            chunks.add(section.strip());
        } else {
            // 超长的 section 内部再用句子切
            chunks.addAll(chunkByChar(section, maxSize, 50));
        }
    }
    return chunks;
}
```

**代码分块**：按函数/类边界切：

```java
// 简化版：按 public/private 方法签名切
String[] codeChunks = code.split("(?=\\n\\s*(public|private|protected)\\s)");
```

#### 策略 4：语义分块（高级）

用 embedding 判断相邻句子的语义相似度，**相似度断崖处切分**：

```java
public List<String> semanticChunk(String text, EmbeddingModel model, double threshold) {
    String[] sentences = text.split("(?<=[。！？.!?])");
    List<float[]> embeddings = Arrays.stream(sentences)
        .map(s -> model.embed(TextSegment.from(s)).content().vector())
        .toList();

    List<String> chunks = new ArrayList<>();
    StringBuilder current = new StringBuilder(sentences[0]);
    for (int i = 1; i < sentences.length; i++) {
        double sim = cosine(embeddings.get(i - 1), embeddings.get(i));
        if (sim < threshold) {
            // 语义断裂 → 切
            chunks.add(current.toString());
            current = new StringBuilder(sentences[i]);
        } else {
            current.append(sentences[i]);
        }
    }
    if (current.length() > 0) chunks.add(current.toString());
    return chunks;
}
```

**优点**：语义边界最自然。
**缺点**：每句调 embedding，**贵且慢**。

#### 策略 5：表格/列表分块（结构化）

**绝对不要切表格**！表格切成块后，**所有行列关系丢失**。

```java
public List<String> chunkWithTables(String text) {
    List<String> chunks = new ArrayList<>();
    Pattern tablePattern = Pattern.compile("(?s)\\|.*?\\|.*?\\n(?:\\|[-: |]+\\n)?(?:\\|.*?\\n)+");

    Matcher m = tablePattern.matcher(text);
    int lastEnd = 0;
    while (m.find()) {
        // 表格前的文本走普通分块
        if (m.start() > lastEnd) {
            chunks.addAll(chunkByChar(text.substring(lastEnd, m.start()), 500, 50));
        }
        // 表格整体作为一块（不切）
        chunks.add("【表格】\n" + m.group());
        lastEnd = m.end();
    }
    if (lastEnd < text.length()) {
        chunks.addAll(chunkByChar(text.substring(lastEnd), 500, 50));
    }
    return chunks;
}
```

## 13.3 五种策略对比

| 策略 | 实现难度 | 召回率 | 速度 | 成本 | 适用 |
|------|----------|--------|------|------|------|
| 字符分块 | ⭐ | 60% | 极快 | 低 | Demo |
| 递归分块 | ⭐⭐ | 80% | 快 | 低 | **生产主流** |
| Markdown/代码 | ⭐⭐⭐ | 85% | 快 | 低 | 文档/代码 |
| 语义分块 | ⭐⭐⭐⭐ | 90% | 慢 | 高 | 高质量 RAG |
| 表格/列表 | ⭐⭐⭐⭐ | 95% | 快 | 低 | 合同/财务 |

> 💡 **生产建议**：递归分块 + 表格保护。简单场景 80% 召回率足够，复杂场景再叠语义分块。

### 13.4.2 不破坏术语

Set<String> PROTECTED_TERMS = Set.of("Spring AI", "LangChain4j", "人工智能", "向量数据库");

String protectTerms(String text) {

## 13.5 分块质量评估

### 13.5.1 指标

| 指标 | 公式 | 目标 |
|------|------|------|
| **块长度方差** | Var(chunk lengths) | 小（大小一致） |
| **块覆盖率** | sum(chunk len) / source len | 接近 1（无遗漏） |
| **召回率（人工评估）** | 命中块数 / 应命中块数 | > 80% |
| **语义完整性** | 块能否独立回答问题 | > 70%（人工抽查） |

### 13.5.2 建立测试集

```java
// 100 个标准 (问题, 应命中片段) 对
List<TestCase> testSet = List.of(
    new TestCase("年假怎么算？", "年假制度：工作满 1 年..."),
    new TestCase("报销流程？", "报销制度：差旅费需...")
);

double passRate = 0;
for (TestCase tc : testSet) {
    List<TextSegment> hits = retriever.findRelevant(tc.question, 5);
    boolean hit = hits.stream().anyMatch(h -> h.text().contains(tc.expectedSnippet));
    if (hit) passRate++;
}
passRate /= testSet.size();
System.out.printf("召回率：%.1f%%%n", passRate * 100);
```

## 关键代码：多格式分块 Pipeline

本章 Demo 实现一个完整的「**解析 → 分块 → 检测**」Pipeline：

```java
package com.jimagent.ch13;

import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;
import java.util.regex.Matcher;
import java.util.regex.Pattern;

/**
 * Ch13: 文档分块策略对比。
 *
 * <p>实现字符分块、递归分块、Markdown 分块、表格保护四种策略。
 *
 * <p>运行：mvn exec:java -pl ch13
 */
public class Main {

    static final String SAMPLE = """
        # 公司制度手册

        ## 第一章 年假制度

        工作满 1 年员工享有 5 天年假。工作满 3 年享有 10 天年假。
        工作满 10 年享有 15 天年假。

        ## 第二章 报销制度

        | 项目 | 限额 | 说明 |
        |------|------|------|
        | 差旅 | 5000/月 | 需附发票 |
        | 餐饮 | 1000/月 | 需附发票 |

        报销需在出差结束后 7 天内提交。
        """;

    public static void main(String[] args) {
        System.out.println("═══════════════════════════════════════");
        System.out.println("Ch13: 文档分块策略对比 Demo");
        System.out.println("═══════════════════════════════════════");
        System.out.println("\n原文（截前 100 字）：\n" +
            SAMPLE.substring(0, Math.min(100, SAMPLE.length())) + "...\n");

        // 1. 字符分块
        System.out.println("─".repeat(50));
        System.out.println("[1] 字符分块（size=80, overlap=20）");
        System.out.println("─".repeat(50));
        List<String> byChar = chunkByChar(SAMPLE, 80, 20);
        printChunks(byChar);

        // 2. 递归分块
        System.out.println("\n" + "─".repeat(50));
        System.out.println("[2] 递归分块（maxSize=80, overlap=20）");
        System.out.println("─".repeat(50));
        List<String> recursive = chunkRecursive(SAMPLE, 80, 20);
        printChunks(recursive);

        // 3. 表格保护
        System.out.println("\n" + "─".repeat(50));
        System.out.println("[3] 表格保护分块");
        System.out.println("─".repeat(50));
        List<String> withTables = chunkWithTables(SAMPLE, 80);
        printChunks(withTables);

        // 4. 统计
        System.out.println("\n" + "─".repeat(50));
        System.out.println("[统计]");
        System.out.println("─".repeat(50));
        stats("字符分块", byChar);
        stats("递归分块", recursive);
        stats("表格保护", withTables);
    }

    /** 字符分块 */
    static List<String> chunkByChar(String text, int size, int overlap) {
        List<String> chunks = new ArrayList<>();
        int step = size - overlap;
        for (int i = 0; i < text.length(); i += step) {
            int end = Math.min(i + size, text.length());
            chunks.add(text.substring(i, end).strip());
            if (end >= text.length()) break;
        }
        return chunks;
    }

    /** 递归分块 */
    static List<String> chunkRecursive(String text, int maxSize, int overlap) {
        String[] seps = {"\n\n", "\n", "。", "！", "？", "；", "，", " "};
        List<String> sentences = new ArrayList<>(List.of(text));
        for (String sep : seps) {
            List<String> next = new ArrayList<>();
            for (String s : sentences) {
                if (s.length() <= maxSize) {
                    next.add(s);
                } else {
                    // 按当前分隔符切，合并相邻的小段
                    String[] parts = s.split(Pattern.quote(sep), -1);
                    StringBuilder cur = new StringBuilder();
                    for (String p : parts) {
                        if (cur.length() + p.length() + sep.length() <= maxSize) {
                            if (!cur.isEmpty()) cur.append(sep);
                            cur.append(p);
                        } else {
                            if (!cur.isEmpty()) next.add(cur.toString());
                            if (p.length() > maxSize) {
                                next.add(p);   // 下一轮再切
                            } else {
                                cur = new StringBuilder(p);
                            }
                        }
                    }
                    if (!cur.isEmpty()) next.add(cur.toString());
                }
            }
            sentences = next;
        }
        // 最后兜底：还是太长的硬切
        List<String> result = new ArrayList<>();
        for (String s : sentences) {
            if (s.length() <= maxSize) result.add(s.strip());
            else result.addAll(chunkByChar(s, maxSize, overlap));
        }
        return result;
    }

    /** 表格保护分块 */
    static List<String> chunkWithTables(String text, int maxSize) {
        List<String> chunks = new ArrayList<>();
        Pattern table = Pattern.compile("(?s)(\\|.*\\|[ \\t]*\\n)(\\|[ :-]+\\|[ \\t]*\\n)((?:\\|.*\\|[ \\t]*\\n)+)");
        Matcher m = table.matcher(text);
        int last = 0;
        while (m.find()) {
            if (m.start() > last) {
                chunks.addAll(chunkRecursive(text.substring(last, m.start()), maxSize, 20));
            }
            chunks.add("【表格保护】\n" + m.group().strip());
            last = m.end();
        }
        if (last < text.length()) {
            chunks.addAll(chunkRecursive(text.substring(last), maxSize, 20));
        }
        return chunks;
    }

    static void printChunks(List<String> chunks) {
        for (int i = 0; i < chunks.size(); i++) {
            String preview = chunks.get(i).replaceAll("\\s+", " ");
            if (preview.length() > 60) preview = preview.substring(0, 60) + "...";
            System.out.printf("  [%d] (%d字) %s%n", i + 1, chunks.get(i).length(), preview);
        }
    }

    static void stats(String name, List<String> chunks) {
        double avg = chunks.stream().mapToInt(String::length).average().orElse(0);
        int max = chunks.stream().mapToInt(String::length).max().orElse(0);
        int min = chunks.stream().mapToInt(String::length).min().orElse(0);
        System.out.printf("  %-8s: 块数=%d, 平均=%.0f, 最小=%d, 最大=%d%n",
            name, chunks.size(), avg, min, max);
    }
}
```

## 常见问题 Q&A

**Q1：分块大小到底选多少？**

A：经验值：
- **OpenAI Embedding**：500 token（约 1500 字符英文 / 750 字中文）
- **BGE 中文模型**：300-500 字符
- **法律/合同**：按条款切（「第 X 条」为边界），每块 200-800 字
- **对话/客服**：每轮对话一块（不超过 500 字）
- **关键**：**做实验对比**，不要照搬数值

**Q2：overlap 多大合适？**

A：10-20% 的 chunk size。太小（<5%）→ 上下文断裂；太大（>30%）→ 浪费存储、检索结果重复。

**Q3：长表格怎么处理？**

A：三种策略：
1. **整体保留**（< 50 行）：表格作为一块
2. **按行 + 表头**（50-500 行）：每行拼上表头作为一块
3. **转成文本**（> 500 行）：`"张三 30岁 工程师"` 比 `["张三", "30", "工程师"]` 检索效果好

**Q4：分块前要清洗文本吗？**

A：**必须**。常见噪声：
- 页眉页脚（PDF）
- 多余空行/空格
- 不可见字符（U+200B 等）
- OCR 错字（扫描件）

**Q5：图片/图表怎么处理？**

A：三种姿势：
1. **多模态模型**（GPT-4V / Claude Vision）：图片直接喂给模型生成描述，再嵌入
2. **图表 OCR**：用 Tesseract 抽取文字
3. **跳过**：纯装饰图直接忽略

**Q6：分块和 embedding 模型有关系吗？**

A：**有**。Embedding 模型有「**最大输入长度**」限制：
- OpenAI `text-embedding-3-small`：8191 token
- BGE `bge-large-zh-v1.5`：512 token
- 超过限制会被**截断**，丢失信息

所以分块大小 ≤ embedding 模型的最大输入。
