## 1. 斜杠命令体系

在编辑器输入 `/` 即触发命令。内置命令分几类：

### 1.1 认证与模型

| 命令 | 说明 |
|------|------|
| `/login` `/logout` | 管理提供商凭证（订阅登录或 API Key） |
| `/model` | 切换模型 |
| `/scoped-models` | 启用/禁用 Ctrl+P 循环的模型 |
| `/settings` | thinking 等级、主题、消息投递方式等 |

### 1.2 会话管理

| 命令 | 说明 |
|------|------|
| `/resume` | 从历史会话中选择恢复 |
| `/new` | 开启新会话 |
| `/name <名称>` | 设置会话显示名 |
| `/session` | 显示会话信息（文件、ID、消息数、token、费用） |
| `/tree` | 跳到会话树任意点继续 |
| `/fork` | 从某条历史消息分支出新会话 |
| `/clone` | 复制当前活动分支为新会话 |

### 1.3 上下文与数据

| 命令 | 说明 |
|------|------|
| `/compact [指令]` | 手动压缩上下文（可带自定义压缩指令） |
| `/copy` | 复制最后一条助手消息 |
| `/export [文件]` | 导出会话为 HTML 或 JSONL |
| `/import <文件>` | 从 JSONL 导入并恢复会话 |
| `/share` | 上传为私有 GitHub gist，得到可分享的 HTML 链接 |

### 1.4 系统

| 命令 | 说明 |
|------|------|
| `/reload` | 重载快捷键、扩展、技能、模板、主题、上下文文件（开发扩展必备） |
| `/trust` | 保存项目信任决定 |
| `/hotkeys` | 显示全部快捷键 |
| `/changelog` | 版本历史 |
| `/quit` | 退出 |

> 💡 扩展开发的命令（`/mycommand`）由 ch19 的 `pi.registerCommand()` 注册；技能是 `/skill:名称`，模板是 `/模板名`——三者都是这个体系的延伸。

## 2. 模型切换快捷键

除了 `/model`，还有三组高频快捷键：

| 操作 | 快捷键 | 说明 |
|------|--------|------|
| 打开模型选择器 | `Ctrl+L` | 列表选择，支持搜索 |
| 循环切模型（前） | `Ctrl+P` | 在 scoped models 中切换 |
| 循环切模型（后） | `Shift+Ctrl+P` | 反向切换 |
| 循环 thinking 等级 | `Shift+Tab` | off → minimal → … → max |

**scoped models**（`/scoped-models` 或 `--models` 参数）：指定一组模型用于 Ctrl+P 循环。典型配置：

```bash
# 启动时限定循环范围
pi --models "claude-*,gpt-4o"

# 会话内管理
/scoped-models
```

> 💡 推荐：把「日常主力模型」和「便宜快速模型」都加进 scoped models——简单任务 Ctrl+P 切到快模型，复杂任务切回强模型。

### Thinking 等级

| 等级 | 适用场景 |
|------|---------|
| `off` | 简单问答、格式化、快速迭代 |
| `minimal` / `low` | 日常编码 |
| `medium` | 默认，复杂任务 |
| `high` / `xhigh` | 架构设计、疑难调试 |
| `max` | 最复杂的推理 |

编辑器边框颜色反映当前等级，一眼可辨。

## 3. 消息队列：在 agent 干活时"插话"

agent 正在执行工具时，你还可以继续输入——消息进入队列，按类型在不同时机投递：

```
        agent 正在干活 ──────────────────────────────►
        ┌─────────┐    ┌─────────┐    ┌──────────┐
 时间线  │ turn 1  │    │ turn 2  │    │ 完成      │
        └─────────┘    └─────────┘    └──────────┘
           ▲               ▲               ▲
 Enter:    │steering        │steering      │
 (steer)   └──┐             └──┐           │
              ▼                ▼           │
   Alt+Enter: └────────────────────────────┘ follow-up
```

| 输入 | 类型 | 投递时机 | 场景 |
|------|------|---------|------|
| `Enter` | **steering** | 当前助手回合的**工具调用完成后** | "等下改成这样"——插话纠偏 |
| `Alt+Enter` | **follow-up** | agent **全部工作完成**后 | "完事后顺便检查 X" |

### 3.1 完整行为

- `Enter` 排队 steering 消息：当前 assistant turn 执行完工具后投递
- `Alt+Enter` 排队 follow-up：agent 全部跑完才投递
- `Escape`：中止 agent，同时把排队的消息**退回编辑器**（可修改重发）
- `Alt+Up`：把排队中的消息取回编辑器

### 3.2 投递模式配置

`/settings` 里可配置投递行为：

| 设置项 | 可选值 | 说明 |
|--------|--------|------|
| `steeringMode` | `one-at-a-time` / `all` | steering 消息逐条回复 vs 全部一次性投递 |
| `followUpMode` | `one-at-a-time` / `all` | follow-up 同理 |
| `transport` | `sse` / `websocket` / `auto` | 提供商传输偏好 |

> ⚠️ Windows Terminal 的 `Alt+Enter` 默认是全屏快捷键，需要先在终端设置里改掉，pi 才能收到 follow-up 快捷键（见 docs/terminal-setup.md）。

## 4. 实战场景

### 4.1 场景一：多模型协作

```bash
# 启动时限定循环范围
pi --models "claude-sonnet-4-6,gpt-4o-mini"
```

任务中用 `Ctrl+P` 随时切换：
- 写代码、重构 → 强模型
- 格式化、命名、简单问答 → 快模型（省钱省时间）

### 4.2 场景二：长任务纠偏（steering）

```
你："重构 payment 模块，用依赖注入替换单例"
[agent 开始改文件…]
你（Enter 排队）："等等，保持现有构造函数签名不变，只改内部实现"
```

steering 会在当前工具调用完成后投递——不用打断 agent，它改完这一步就能收到纠正。

### 4.3 场景三：任务接力（follow-up）

```
你："重构 payment 模块"
[agent 开始干活…]
你（Alt+Enter 排队）："完事后跑一遍全部测试并汇报结果"
```

follow-up 等 agent 全部完成后再投递，适合追加“收尾型”任务，不会中途打断思路。

## 5. 常见问题 Q&A

**Q1：排队的消息怎么取消？**
A：按 `Escape` 中止当前任务，排队消息会退回编辑器；或按 `Alt+Up` 单独取回修改。

**Q2：steering 和 follow-up 能同时排队多条吗？**
A：能。默认逐条投递（`one-at-a-time`），也可在 `/settings` 改为 `all` 一次性投递全部。

**Q3：为什么有时候 Enter 没排队而是直接发不出去？**
A：agent 空闲时 Enter 就是普通发送；只有 agent 正在跑时 Enter 才进入队列。想要“无论如何都排队”，始终在干活时输入即可。

**Q4：`/settings` 改了 transport 有什么用？**
A：部分提供商支持 sse / websocket 两种流式传输；`auto` 自动选择。若遇到断流、延迟异常，可手动指定试试。

## 6. 动手试试

1. 在项目里跑一个长任务（如"重构这个模块"）
2. 趁 agent 干活时，用 `Enter` 排一条 steering 消息（如"把函数命名改成驼峰"），观察它在工具调用间隙被投递
3. 再用 `Alt+Enter` 排一条 follow-up（如"完事后跑一遍测试"），观察它最后投递
4. 按 `Escape` 中止，观察排队消息回到编辑器
5. 用 `/session` 查看会话信息；用 `/export session.html` 导出；用 `/share` 得到分享链接

## 7. 小结

| 要点 | 说明 |
|------|------|
| `/` 命令 | 认证/模型/会话/上下文/系统五大类 |
| 模型切换 | `/model`、Ctrl+L、Ctrl+P + scoped models |
| thinking 等级 | off→max 七档，Shift+Tab 切换，边框颜色提示 |
| steering | Enter 排队，工具调用完成后投递（纠偏） |
| follow-up | Alt+Enter 排队，全部完成后投递（追加任务） |
| 取回 | Escape 中止并把排队消息退回编辑器；Alt+Up 取回 |
