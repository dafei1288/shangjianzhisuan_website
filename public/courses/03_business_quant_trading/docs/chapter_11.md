## 11.1 用AI阅读量化论文：快速提取核心思路

量化研究的核心竞争力之一是快速消化学术论文。一篇顶级期刊论文动辄40-60页，充满数学公式和统计术语。AI可以把这个过程从"几天"压缩到"几小时"。

**标准的论文阅读提示词模板：**

```
你是一位量化交易研究员，请帮我分析以下论文摘要/全文。

论文内容：
[粘贴论文摘要或关键章节]

请按以下结构输出分析：

1. 核心思路（100字以内）
   - 这篇论文解决了什么问题？
   - 核心创新点是什么？

2. 策略逻辑
   - 选股/择时的核心信号是什么？
   - 信号的经济学解释是什么？

3. 关键参数
   - 回测区间、市场、频率
   - 主要超参数

4. 核心结论
   - 年化收益率、夏普比率、最大回撤
   - 与基准的对比

5. 可复现性评估
   - 数据是否容易获取？
   - 实现难度（1-5分）
   - 潜在的数据泄露风险

6. 改进建议
   - 如果要在A股市场应用，需要做哪些调整？
```

**实际案例：分析动量因子论文**

把Jegadeesh & Titman (1993) 的经典动量论文摘要粘贴给AI，AI会告诉你：核心思路是过去3-12个月表现好的股票，未来3-12个月仍会继续表现好；信号是过去N个月的累计收益率；在A股应用时需要注意反转效应更强、动量效应更弱的特点。

**进阶技巧：让AI比较多篇论文**

```
我有以下3篇关于动量策略的论文摘要，请帮我：
1. 找出它们的共同结论
2. 找出它们的主要分歧
3. 综合来看，哪个版本最适合在A股日线数据上实现？

论文1：[摘要]
论文2：[摘要]
论文3：[摘要]
```

## 11.2 用AI复现经典策略：从论文到代码

读懂论文只是第一步，把它变成可运行的代码才是真正的价值。

**复现策略的标准提示词流程：**

**第一步：理解策略逻辑**
```
请用伪代码描述以下策略的实现步骤：

策略名称：12-1动量策略
核心逻辑：
- 每月末，计算所有股票过去12个月（排除最近1个月）的累计收益率
- 买入收益率最高的前20%股票（赢家组合）
- 卖出收益率最低的后20%股票（输家组合）
- 持有1个月后重新调仓

请给出：
1. 详细的实现步骤（伪代码）
2. 需要注意的技术细节（如何处理停牌、退市等）
3. 可能的陷阱（数据泄露、幸存者偏差等）
```

**第二步：生成代码框架**
```
基于上面的伪代码，请用Python实现这个动量策略。
要求：
- 使用pandas处理数据
- 数据格式：DataFrame，列名为 date, stock_code, close, return_1m
- 函数化设计，每个步骤一个函数
- 添加详细注释
- 不需要回测框架，只需要生成每期的持仓信号
```

**第三步：代码审查和优化**
```
请审查以下动量策略代码，检查：
1. 是否存在数据泄露（用了未来数据）
2. 是否正确处理了停牌股票
3. 是否有幸存者偏差（只用了现存股票）
4. 代码效率是否可以优化

[粘贴代码]
```

## 11.3 用AI做策略诊断：找出策略的薄弱环节

当策略回测结果不理想，或者实盘表现与回测偏差较大时，AI可以帮助系统性地诊断问题。

**策略诊断提示词模板：**

```
我的量化策略出现了以下问题，请帮我诊断原因并给出改进建议：

策略描述：
[简述策略逻辑]

问题现象：
- 回测年化收益：25%，实盘年化收益：8%
- 回测最大回撤：15%，实盘最大回撤：28%
- 回测夏普比率：1.8，实盘夏普比率：0.6

回测参数：
- 回测区间：2018-2023
- 手续费设置：0.1%单边
- 滑点设置：0

请从以下角度分析：
1. 过拟合风险（参数是否过度优化？）
2. 交易成本低估（实际手续费+滑点是多少？）
3. 市场冲击（策略容量是否有限？）
4. 数据质量问题（是否有幸存者偏差？）
5. 市场环境变化（策略是否只在特定市场环境有效？）

请给出每个方面的可能性评分（1-5分）和具体改进建议。
```

**常见策略问题的AI诊断示例：**

问题：策略在2019-2020年表现很好，2021年后大幅跑输。

AI诊断提示词：
```
我的动量策略在2021年后表现急剧下滑。
2019-2020年：年化收益35%，夏普1.9
2021-2023年：年化收益-5%，夏普-0.3

请分析：
1. 2021年A股市场发生了哪些结构性变化？
2. 动量策略在什么市场环境下容易失效？
3. 如何改造策略使其更具适应性？
```

## 11.4 Prompt工程进阶：为量化场景设计专用提示词模板

好的提示词就像好的问题——问题问得准，答案才有价值。

**量化场景的Prompt设计原则：**

**原则1：给AI一个角色**
```
# 差的写法
"帮我分析这个策略"

# 好的写法
"你是一位有15年经验的量化基金经理，专注于A股市场。
请从风险管理的角度分析以下策略..."
```

**原则2：提供足够的上下文**
```
# 差的写法
"这个代码有什么问题？"

# 好的写法
"以下是一个A股日线动量策略的Python代码。
背景：
- 数据来源：akshare，前复权日线数据
- 回测区间：2018-2024
- 目标：月度调仓，持有前20%动量股票
- 已知问题：回测夏普比率1.8，但实盘只有0.6

请检查代码中可能导致回测虚高的问题：
[代码]"
```

**原则3：要求结构化输出**
```
请按以下格式输出分析结果：

## 问题诊断
[列出发现的问题，每个问题一行]

## 严重程度
[高/中/低，并说明理由]

## 修复方案
[具体的代码修改建议]

## 预期改善
[修复后预计对回测结果的影响]
```

**原则4：迭代优化**

不要期望一次提示词就得到完美答案。先得到初步结果，再追问细节：
```
你提到"可能存在前视偏差"，请具体指出是代码的哪一行，
并给出修复后的代码。
```

**量化专用提示词模板库：**

```python
# 可以把这些模板保存为Python字符串，方便复用

TEMPLATES = {
    "paper_analysis": """
你是量化研究员，请分析以下论文：
{paper_content}

输出：核心思路、策略逻辑、关键参数、A股适用性评估
""",
    
    "code_review": """
你是资深量化工程师，请审查以下策略代码：
{code}

检查：数据泄露、幸存者偏差、交易成本处理、代码效率
""",
    
    "strategy_diagnosis": """
策略描述：{strategy_desc}
回测结果：{backtest_results}
实盘结果：{live_results}

请诊断回测与实盘偏差的原因，并给出改进建议。
""",
    
    "feature_engineering": """
数据：{data_description}
目标：{prediction_target}

请设计10个有量化逻辑支撑的特征，每个特征说明经济含义和Python计算方法。
"""
}

def build_prompt(template_name: str, **kwargs) -> str:
    """根据模板名称和参数构建提示词"""
    template = TEMPLATES.get(template_name, "")
    return template.format(**kwargs)
```

## 11.5 构建个人量化知识库：让AI记住你的策略偏好

每次和AI对话都要重新解释背景，效率很低。通过构建个人知识库，可以让AI快速了解你的偏好和历史工作。

**方法1：系统提示词（System Prompt）**

在每次对话开始时，加入一段描述你偏好的系统提示词：

```
你是我的量化交易助手。以下是关于我的背景信息：

投资风格：
- 主要市场：A股，偶尔做加密货币
- 交易频率：日线级别，月度调仓
- 风险偏好：中等，最大回撤不超过20%
- 持仓数量：通常10-20只股票

技术栈：
- 语言：Python 3.10
- 数据：akshare获取A股数据
- 回测框架：自己写的简单回测，不用backtrader
- 常用库：pandas, numpy, sklearn, xgboost

已有策略：
- 动量策略（月度调仓，已上线）
- 低波动因子策略（开发中）

偏好：
- 代码风格：函数式，有详细注释
- 不喜欢过度复杂的模型，偏好可解释性
- 重视风险管理，宁可少赚也要控制回撤
```

**方法2：Markdown知识库文件**

创建一个 `quant_knowledge_base.md` 文件，记录你的策略、发现和偏好：

```markdown
# 个人量化知识库

## 已验证的有效因子
- 动量因子（12-1月）：A股有效，但效果弱于美股
- 低波动因子：A股有效，尤其在熊市
- 盈利质量因子（ROE稳定性）：有效

## 已验证的无效因子
- 纯技术指标（RSI、MACD）：单独使用效果差
- 短期反转（1周）：交易成本吃掉大部分收益

## 重要发现
- A股动量效应在1-3个月最强，超过6个月开始反转
- 小市值股票流动性差，实盘滑点远高于回测假设

## 待研究方向
- 基于财报文本的情绪因子
- 行业轮动策略
```

每次和AI对话时，把相关部分粘贴进去，AI就能基于你的历史工作给出更有针对性的建议。

## 实战练习：用AI复现一个经典动量策略，并与原论文结果对比

### 目标
复现Jegadeesh & Titman (1993) 的12-1月动量策略，在A股数据上测试，并与原论文结果对比。

### 步骤

**Step 1：用AI理解策略**

向AI输入以下提示词：
```
请解释12-1动量策略的具体实现步骤：
- 每月末，计算每只股票过去12个月（跳过最近1个月）的累计收益率
- 按收益率排序，买入前20%（赢家），卖出后20%（输家）
- 持有1个月

请给出：
1. 为什么要跳过最近1个月？
2. 在A股实现时需要注意什么？
3. 完整的Python实现代码
```

**Step 2：完整实现代码**

```python
import akshare as ak
import pandas as pd
import numpy as np
from datetime import datetime

def get_a_share_data(start_date: str, end_date: str) -> pd.DataFrame:
    """
    获取A股全市场日线数据
    注意：实际使用时需要处理大量数据，建议先用少量股票测试
    """
    # 获取股票列表
    stock_list = ak.stock_zh_a_spot_em()
    codes = stock_list['代码'].tolist()[:100]  # 先用100只股票测试
    
    all_data = []
    for code in codes[:10]:  # 演示用，只取10只
        try:
            df = ak.stock_zh_a_hist(symbol=code, period="monthly",
                                     start_date=start_date, end_date=end_date,
                                     adjust="qfq")
            df['stock_code'] = code
            df.columns = ['date', 'open', 'close', 'high', 'low', 'volume',
                         'amount', 'amplitude', 'pct_change', 'change', 
                         'turnover', 'stock_code']
            all_data.append(df[['date', 'stock_code', 'close']])
        except:
            continue
    
    return pd.concat(all_data, ignore_index=True)


def calculate_momentum_signal(price_df: pd.DataFrame, 
                               lookback: int = 12, 
                               skip: int = 1) -> pd.DataFrame:
    """
    计算12-1动量信号
    
    lookback: 回看期（月）
    skip: 跳过最近几个月（避免短期反转）
    """
    price_df = price_df.copy()
    price_df['date'] = pd.to_datetime(price_df['date'])
    price_df = price_df.sort_values(['stock_code', 'date'])
    
    # 计算月度收益率
    price_df['monthly_ret'] = price_df.groupby('stock_code')['close'].pct_change()
    
    # 计算过去lookback个月（跳过最近skip个月）的累计收益率
    def calc_momentum(group):
        # 过去12个月的收益，但跳过最近1个月
        # 即：用t-12到t-1月的收益，不用t月
        group = group.sort_values('date')
        group['momentum'] = (
            group['monthly_ret']
            .shift(skip)                    # 跳过最近1个月
            .rolling(lookback)              # 过去12个月
            .apply(lambda x: (1 + x).prod() - 1)  # 累计收益率
        )
        return group
    
    result = price_df.groupby('stock_code').apply(calc_momentum)
    return result.reset_index(drop=True)


def generate_momentum_portfolio(signal_df: pd.DataFrame, 
                                  top_pct: float = 0.2) -> pd.DataFrame:
    """
    根据动量信号生成投资组合
    
    top_pct: 买入前top_pct的股票
    """
    portfolios = []
    
    for date, group in signal_df.groupby('date'):
        group = group.dropna(subset=['momentum'])
        if len(group) < 10:  # 股票数量太少则跳过
            continue
        
        n_stocks = max(1, int(len(group) * top_pct))
        
        # 赢家组合（动量最高）
        winners = group.nlargest(n_stocks, 'momentum')['stock_code'].tolist()
        # 输家组合（动量最低）
        losers = group.nsmallest(n_stocks, 'momentum')['stock_code'].tolist()
        
        portfolios.append({
            'date': date,
            'winners': winners,
            'losers': losers,
            'n_total': len(group)
        })
    
    return pd.DataFrame(portfolios)


# 执行回测
print("获取数据...")
price_data = get_a_share_data("20180101", "20241231")

print("计算动量信号...")
signal_data = calculate_momentum_signal(price_data)

print("生成投资组合...")
portfolio_data = generate_momentum_portfolio(signal_data)

print(f"\n生成了 {len(portfolio_data)} 期投资组合")
print("\n最新一期赢家组合：")
print(portfolio_data.iloc[-1]['winners'])
```

## 常见问题 Q&A

**Q1：让 AI 帮我读论文、做诊断，是不是就不用自己做研究了？**

A：恰恰相反。AI 最适合帮你加速“读、整理、比较、初步诊断”，但真正决定研究质量的，仍然是你是否能识别假设、验证逻辑、判断证据强弱。

**Q2：AI 给出的优化建议很多，我应该全部尝试吗？**

A：不要。更稳的做法是一次只验证少量明确假设，并为每次修改记录“改了什么、为什么改、结果怎样”。否则你很快就会进入“改了很多，但不知道哪一步真正有效”的状态。

**Q3：为什么课程里强调知识库和研究记录？**

A：因为量化研究最大的隐性成本之一就是重复踩坑。没有结构化记录，你下个月很可能又回到同一个错误假设上；有记录，AI 才能真正帮你做连续性的研究辅助。
