### 2. 项目模块依赖关系

JimSQL 的模块之间有清晰的依赖层次，理解这个层次是阅读源码的关键：

```
catalog（元数据）
    ↑
storage（存储层）← 最底层，不依赖其他模块
    ↑
index（索引层）
    ↑
sql（SQL 解析）
    ↑
executor（执行引擎）← 依赖所有下层
    ↑
transaction（事务）
    ↑
recovery（恢复）
    ↑
JimSQL（顶层入口）
```

**阅读源码的正确顺序**：从底层往上，先读 `storage`，再读 `sql`，最后读 `executor`。

### 3. 如何阅读数据库源码

数据库源码通常很复杂，推荐以下方法：

1. **从入口追踪**：找到 `main()` 或顶层 API，用调试器单步执行一条 SQL
2. **关注数据流**：数据（Tuple）是如何从磁盘流向结果集的
3. **忽略优化细节**：第一遍阅读时跳过复杂的优化逻辑，只看主干
4. **画调用链图**：每读一个模块，画出它调用了哪些方法

## 代码讲解

### 2.1 JimSQL 顶层 API

JimSQL 提供了一个简洁的顶层入口，屏蔽了内部复杂性：

```java
// JimSQL 的顶层入口（简化版）
public class JimSQL implements AutoCloseable {

    private final Catalog catalog;
    private final BufferPool bufferPool;
    private final LogManager logManager;

    public JimSQL(String dataDir) throws Exception {
        // 1. 初始化数据目录
        File dir = new File(dataDir);
        dir.mkdirs();

        // 2. 初始化各子系统（顺序很重要）
        this.catalog = new Catalog(dataDir);
        this.bufferPool = new BufferPool(catalog, 100); // 100 页缓冲
        this.logManager = new LogManager(dataDir + "/wal.log");

        // 3. 崩溃恢复（如果上次异常退出）
        Recovery.recover(logManager, bufferPool, catalog);
    }

    public void execute(String sql) throws Exception {
        // 解析 → 绑定 → 执行
        Statement stmt = Parser.parse(sql);
        stmt = Binder.bind(stmt, catalog);
        Executor.execute(stmt, bufferPool, catalog, logManager);
    }

    public ResultSet query(String sql) throws Exception {
        Statement stmt = Parser.parse(sql);
        stmt = Binder.bind(stmt, catalog);
        return Executor.query(stmt, bufferPool, catalog);
    }

    @Override
    public void close() throws Exception {
        bufferPool.flushAll(); // 刷新所有脏页
        logManager.close();
    }
}
```

注意 `execute()` 和 `query()` 的区别：
- `execute()`：用于 DDL（CREATE/DROP）和 DML（INSERT/UPDATE/DELETE），无返回结果集
- `query()`：用于 SELECT，返回 `ResultSet` 迭代器

### 2.2 第一个完整示例

```java
import com.jimsql.JimSQL;
import com.jimsql.ResultSet;

public class FirstQuery {

    public static void main(String[] args) throws Exception {
        // 使用 try-with-resources 确保资源释放
        try (JimSQL db = new JimSQL("./first_db")) {

            // Step 1: 建表
            db.execute("""
                CREATE TABLE students (
                    id    INT,
                    name  VARCHAR(50),
                    score INT
                )
            """);
            System.out.println("表创建成功");

            // Step 2: 插入数据
            db.execute("INSERT INTO students VALUES (1, '张三', 90)");
            db.execute("INSERT INTO students VALUES (2, '李四', 75)");
            db.execute("INSERT INTO students VALUES (3, '王五', 88)");
            db.execute("INSERT INTO students VALUES (4, '赵六', 62)");
            System.out.println("数据插入成功");

            // Step 3: 全表查询
            System.out.println("\n全表数据:");
            ResultSet all = db.query("SELECT * FROM students");
            printResultSet(all);

            // Step 4: 条件查询
            System.out.println("\nscore > 80 的学生:");
            ResultSet filtered = db.query(
                "SELECT name, score FROM students WHERE score > 80"
            );
            printResultSet(filtered);

            // Step 5: 聚合查询
            System.out.println("\n平均分:");
            ResultSet avg = db.query("SELECT AVG(score) FROM students");
            printResultSet(avg);
        }
        // try 块结束时自动调用 db.close()
    }

    static void printResultSet(ResultSet rs) throws Exception {
        // 打印列名
        String[] cols = rs.getColumnNames();
        System.out.println("  " + String.join(" | ", cols));
        System.out.println("  " + "-".repeat(30));

        // 打印数据行
        int count = 0;
        while (rs.next()) {
            StringBuilder row = new StringBuilder("  ");
            for (String col : cols) {
                row.append(rs.getString(col)).append(" | ");
            }
            System.out.println(row);
            count++;
        }
        System.out.println("  共 " + count + " 行");
    }
}
```

### 2.3 追踪一条 SELECT 的调用链

用调试器在 `db.query("SELECT name FROM students WHERE score > 80")` 处打断点，追踪调用链：

```
JimSQL.query(sql)
  └─ Parser.parse(sql)
       └─ Lexer.tokenize(sql)          // "SELECT" "name" "FROM" ...
       └─ Parser.parseSelect()         // 构建 SelectStatement AST
  └─ Binder.bind(stmt, catalog)
       └─ catalog.getTable("students") // 验证表存在
       └─ 验证 name、score 列存在
  └─ Executor.query(stmt, bufferPool, catalog)
       └─ 构建算子树: Filter → SeqScan
       └─ SeqScan.open()               // 打开 HeapFile
       └─ Filter.next()                // 逐行过滤
            └─ SeqScan.next()          // 从 BufferPool 读取 Tuple
                 └─ BufferPool.getPage(pageId)  // 缓存命中或从磁盘读
```

这条调用链就是本课程后续章节的学习路线图。

### 2.4 数据文件结构

JimSQL 在数据目录下创建以下文件：

```
./first_db/
  catalog.json        ← 表结构元数据（表名、列名、类型）
  students.db         ← students 表的数据文件（HeapFile）
  students.idx        ← students 表的索引文件（如果有）
  wal.log             ← Write-Ahead Log（事务日志）
```

可以用十六进制编辑器查看 `students.db`，观察数据是如何以页（Page）为单位存储的：

```java
// 查看数据文件的前 4096 字节（一个 Page）
import java.io.*;
import java.nio.file.*;

public class ViewDataFile {
    public static void main(String[] args) throws Exception {
        byte[] data = Files.readAllBytes(Path.of("./first_db/students.db"));
        System.out.println("文件大小: " + data.length + " 字节");
        System.out.println("页数: " + (data.length / 4096));

        // 打印第一页的前 64 字节（十六进制）
        System.out.println("\n第一页前 64 字节（十六进制）:");
        for (int i = 0; i < Math.min(64, data.length); i++) {
            System.out.printf("%02X ", data[i]);
            if ((i + 1) % 16 == 0) System.out.println();
        }
    }
}
```

## 常见问题

### Q1：Maven 构建失败怎么办？

常见原因：
1. **Java 版本不匹配**：检查 `pom.xml` 中的 `<java.version>`，确保本地 Java 版本 ≥ 要求版本
2. **网络问题**：Maven 需要下载依赖，确保能访问 Maven Central。国内可配置阿里云镜像：
   ```xml
   <!-- ~/.m2/settings.xml -->
   <mirror>
     <id>aliyun</id>
     <url>https://maven.aliyun.com/repository/public</url>
     <mirrorOf>central</mirrorOf>
   </mirror>
   ```
3. **编译错误**：先运行 `mvn clean`，再重新 `mvn compile`

### Q2：数据目录已存在时会怎样？

JimSQL 在初始化时会检查数据目录：
- 如果目录存在且有 `catalog.json`，则加载已有的表结构
- 如果目录为空，则初始化新数据库
- 如果目录存在但 `catalog.json` 损坏，会抛出异常（需要手动清理）

### Q3：如何在 IntelliJ IDEA 中调试？

1. 打开项目：`File → Open → 选择 jimsql 目录`
2. 等待 Maven 索引完成
3. 在 `JimSQL.java` 的 `query()` 方法第一行打断点
4. 右键 `FirstQuery.java` → `Debug 'FirstQuery.main()'`
5. 使用 `F7`（Step Into）追踪调用链

## 本章小结

本章完成了开发环境搭建，并建立了对 JimSQL 的整体认知：

1. **构建流程**：`git clone → mvn compile → mvn test`
2. **模块依赖**：storage → index → sql → executor → transaction → recovery
3. **顶层 API**：`JimSQL.execute()` 处理 DDL/DML，`JimSQL.query()` 处理 SELECT
4. **调用链**：Parser → Binder → Executor → BufferPool → HeapFile
5. **数据文件**：`.db`（数据）、`.idx`（索引）、`wal.log`（日志）
