## 3. 核心概念

### 3.1 为什么以页为单位？

磁盘的物理特性决定了它的最小读写单位不是1字节，而是一个"扇区"（通常512字节）或"块"（通常4096字节）。即使你只想读1字节，操作系统也会把整个块都读进来。

```
磁盘 I/O 的现实：

你想要的：  [1字节]
实际读取：  [─────────── 4096字节 ───────────]
                        ↑
                   你要的1字节在这里

结论：既然必须读4096字节，不如把这4096字节都利用起来！
```

**I/O 放大问题**：如果每次只存一行数据（100字节），但每次 I/O 读写4096字节，那么有效数据只占 100/4096 ≈ 2.4%，其余97.6%都是浪费。

**解决方案**：以页（Page）为单位组织数据，每页存放尽可能多的行，让每次 I/O 都物尽其用。

```
页大小 = 4096 字节
每行大小 = 100 字节
每页可存行数 = 4096 / 100 ≈ 40 行

读1行 vs 读1页：
  逐行读取 40 行：40 次 I/O
  按页读取 40 行：1 次 I/O
  效率提升：40 倍
```

### 3.2 HeapPage 结构

HeapPage 是 JimSQL 中最基本的页类型，采用"堆文件"组织方式（行无序存放）。

```
HeapPage 内存布局（页大小 = PAGE_SIZE 字节）：

┌─────────────────────────────────────────────────────────┐
│                     页头（Header）                       │
│  [4字节 pageId] [4字节 slotCount] [4字节 tupleSize]     │
├─────────────────────────────────────────────────────────┤
│                   槽位图（Slot Bitmap）                   │
│  每个槽位占1位：1=有数据，0=空槽                         │
│  ceil(slotCount / 8) 字节                               │
├─────────────────────────────────────────────────────────┤
│                    Tuple 区                              │
│  槽位0: [tupleSize字节]                                  │
│  槽位1: [tupleSize字节]                                  │
│  槽位2: [tupleSize字节]  ← 已删除，位图标记为0           │
│  ...                                                     │
│  槽位N: [tupleSize字节]                                  │
└─────────────────────────────────────────────────────────┘
```

**关键设计**：
- 每个槽位（Slot）的大小固定为 `tupleSize` 字节
- 槽位图记录哪些槽位有有效数据
- 删除操作只需把槽位图对应位清零，不需要移动数据（"标记删除"）
- 插入时优先复用已删除的槽位

### 3.3 槽位图（Slot Bitmap）

槽位图是一个紧凑的位数组，每个槽位占1位：

```
假设 slotCount = 10，槽位图占 ceil(10/8) = 2 字节：

字节0: [位7 位6 位5 位4 位3 位2 位1 位0]
        槽7  槽6  槽5  槽4  槽3  槽2  槽1  槽0

字节1: [位7 位6 位5 位4 位3 位2 位1 位0]
        ---  ---  ---  ---  ---  ---  槽9  槽8

示例：槽0、1、3、4、8 有数据，槽2、5、6、7、9 为空：
字节0: [0  0  0  1  1  0  1  1] = 0x1B
字节1: [0  0  0  0  0  0  0  1] = 0x01
```

槽位图操作：

```java
// 检查槽位 slotNo 是否有数据
boolean isSlotUsed(byte[] bitmap, int slotNo) {
    int byteIndex = slotNo / 8;
    int bitIndex  = slotNo % 8;
    return (bitmap[byteIndex] & (1 << bitIndex)) != 0;
}

// 标记槽位 slotNo 为已使用
void setSlotUsed(byte[] bitmap, int slotNo) {
    int byteIndex = slotNo / 8;
    int bitIndex  = slotNo % 8;
    bitmap[byteIndex] |= (byte)(1 << bitIndex);
}

// 标记槽位 slotNo 为空（删除）
void setSlotEmpty(byte[] bitmap, int slotNo) {
    int byteIndex = slotNo / 8;
    int bitIndex  = slotNo % 8;
    bitmap[byteIndex] &= (byte)~(1 << bitIndex);
}
```

### 3.4 PageId 的设计

PageId 唯一标识一个页，由两部分组成：

```java
class PageId {
    final int tableId;  // 属于哪张表
    final int pageNo;   // 表内第几页（从0开始）

    PageId(int tableId, int pageNo) {
        this.tableId = tableId;
        this.pageNo  = pageNo;
    }
}
```

为什么需要 tableId？因为一个数据库可能有多张表，每张表都有自己的页文件。PageId 确保全局唯一性，这在后面的缓冲池（Ch05）中至关重要。

### 3.5 HeapFile：多页文件的组织

HeapFile 是一张表对应的磁盘文件，由多个 HeapPage 顺序排列组成：

```
HeapFile（表文件）：

┌──────────────┬──────────────┬──────────────┬──────────────┐
│   Page 0     │   Page 1     │   Page 2     │   Page 3     │
│ (4096 字节)  │ (4096 字节)  │ (4096 字节)  │ (4096 字节)  │
└──────────────┴──────────────┴──────────────┴──────────────┘
     ↑                ↑
  第0页偏移=0      第1页偏移=4096

读取第 N 页：seek(N * PAGE_SIZE)，读取 PAGE_SIZE 字节
```

HeapFile 提供两个核心接口：
- `readPage(pageNo)` → 从磁盘读取第 N 页
- `writePage(page)` → 把页写回磁盘

### 4.2 HeapPage 核心实现

```java
class HeapPage {
    static final int PAGE_SIZE   = 4096;  // 页大小：4KB
    static final int HEADER_SIZE = 12;    // 页头：pageId(4) + slotCount(4) + tupleSize(4)

    private final PageId pageId;
    private final int    tupleSize;   // 每个 Tuple 的固定字节数
    private final int    slotCount;   // 本页最多容纳的 Tuple 数
    private final byte[] bitmap;      // 槽位图
    private final byte[] tupleData;   // Tuple 数据区

    HeapPage(PageId pageId, int tupleSize) {
        this.pageId    = pageId;
        this.tupleSize = tupleSize;

        // 计算槽位数：页大小 - 页头 = 可用空间
        // 每个槽位占 tupleSize 字节 + 1/8 字节（位图）
        // slotCount * tupleSize + ceil(slotCount/8) <= PAGE_SIZE - HEADER_SIZE
        // 近似计算：slotCount = (PAGE_SIZE - HEADER_SIZE) * 8 / (tupleSize * 8 + 1)
        int available = PAGE_SIZE - HEADER_SIZE;
        this.slotCount = (available * 8) / (tupleSize * 8 + 1);

        int bitmapSize = (slotCount + 7) / 8;
        this.bitmap    = new byte[bitmapSize];
        this.tupleData = new byte[slotCount * tupleSize];
    }

    // 检查槽位是否有数据
    boolean isSlotUsed(int slotNo) {
        return (bitmap[slotNo / 8] & (1 << (slotNo % 8))) != 0;
    }

    // 标记槽位为已使用
    private void setSlotUsed(int slotNo) {
        bitmap[slotNo / 8] |= (byte)(1 << (slotNo % 8));
    }

    // 标记槽位为空
    private void setSlotEmpty(int slotNo) {
        bitmap[slotNo / 8] &= (byte)(~(1 << (slotNo % 8)));
    }

    // 插入 Tuple，返回槽位号；页满返回 -1
    int insertTuple(byte[] tupleBytes) {
        if (tupleBytes.length != tupleSize) {
            throw new IllegalArgumentException(
                "Tuple size mismatch: expected " + tupleSize + ", got " + tupleBytes.length);
        }
        // 找第一个空槽
        for (int slot = 0; slot < slotCount; slot++) {
            if (!isSlotUsed(slot)) {
                // 写入数据
                int offset = slot * tupleSize;
                System.arraycopy(tupleBytes, 0, tupleData, offset, tupleSize);
                setSlotUsed(slot);
                return slot;
            }
        }
        return -1;  // 页已满
    }

    // 删除指定槽位的 Tuple
    void deleteTuple(int slotNo) {
        if (slotNo < 0 || slotNo >= slotCount) {
            throw new IndexOutOfBoundsException("Invalid slot: " + slotNo);
        }
        if (!isSlotUsed(slotNo)) {
            throw new IllegalStateException("Slot " + slotNo + " is already empty");
        }
        setSlotEmpty(slotNo);
        // 可选：清零数据区（安全考虑）
        int offset = slotNo * tupleSize;
        Arrays.fill(tupleData, offset, offset + tupleSize, (byte)0);
    }

    // 读取指定槽位的 Tuple 字节
    byte[] getTupleBytes(int slotNo) {
        if (!isSlotUsed(slotNo)) return null;
        int offset = slotNo * tupleSize;
        return Arrays.copyOfRange(tupleData, offset, offset + tupleSize);
    }

    // 统计已使用槽位数
    int usedSlots() {
        int count = 0;
        for (int i = 0; i < slotCount; i++) {
            if (isSlotUsed(i)) count++;
        }
        return count;
    }

    boolean isFull()  { return usedSlots() == slotCount; }
    boolean isEmpty() { return usedSlots() == 0; }

    PageId getPageId()   { return pageId; }
    int    getSlotCount(){ return slotCount; }
    int    getTupleSize(){ return tupleSize; }
}
```

### 4.3 HeapFile 实现

```java
class HeapFile {
    private final int tableId;
    private final TupleDesc schema;
    private final int tupleSize;
    private final List<HeapPage> pages;

    HeapFile(int tableId, TupleDesc schema, int tupleSize) {
        this.tableId   = tableId;
        this.schema    = schema;
        this.tupleSize = tupleSize;
        this.pages     = new ArrayList<>();
    }

    // 插入 Tuple：找有空位的页，没有则新建页
    PageId insertTuple(byte[] tupleBytes) {
        // 遍历现有页，找有空位的
        for (HeapPage page : pages) {
            int slot = page.insertTuple(tupleBytes);
            if (slot >= 0) {
                return page.getPageId();
            }
        }
        // 所有页都满了，新建一页
        HeapPage newPage = new HeapPage(
            new PageId(tableId, pages.size()), tupleSize);
        int slot = newPage.insertTuple(tupleBytes);
        assert slot >= 0 : "新页插入失败";
        pages.add(newPage);
        return newPage.getPageId();
    }

    // 读取指定页
    HeapPage readPage(int pageNo) {
        if (pageNo < 0 || pageNo >= pages.size()) {
            throw new IndexOutOfBoundsException("Page not found: " + pageNo);
        }
        return pages.get(pageNo);
    }

    int numPages()  { return pages.size(); }
    int getTableId(){ return tableId; }
    TupleDesc getSchema() { return schema; }
}
```

### 4.4 完整的插入/删除/遍历流程

```java
// 创建表
TupleDesc schema = TupleDesc.of(
    new String[]{"id", "score"},
    new Type[]{Type.INT, Type.INT}
);
int tupleSize = 8;  // 2个INT字段，各4字节
HeapFile file = new HeapFile(1, schema, tupleSize);

// 插入数据
for (int i = 1; i <= 5; i++) {
    Tuple t = new Tuple(schema, new Field[]{
        new IntField(i), new IntField(i * 10)
    });
    file.insertTuple(t.serialize());
}

// 遍历第0页的所有有效 Tuple
HeapPage page = file.readPage(0);
for (int slot = 0; slot < page.getSlotCount(); slot++) {
    if (page.isSlotUsed(slot)) {
        byte[] bytes = page.getTupleBytes(slot);
        Tuple t = Tuple.deserialize(bytes, schema);
        System.out.println("槽位" + slot + ": " + t);
    }
}

// 删除槽位1的数据
page.deleteTuple(1);
System.out.println("删除后已用槽位数: " + page.usedSlots());

// 再插入一行，验证槽位复用
Tuple newTuple = new Tuple(schema, new Field[]{
    new IntField(99), new IntField(999)
});
int newSlot = page.insertTuple(newTuple.serialize());
System.out.println("新数据插入到槽位: " + newSlot);  // 应该是1（复用）
```

## 6. 常见问题

**Q1：为什么槽位图用位（bit）而不是字节（byte）来标记？**

A：节省空间。如果用1字节标记一个槽位，那么对于一个有300个槽位的页，需要300字节的位图，占页大小的7.3%。用位图只需 ceil(300/8) = 38 字节，仅占0.9%。这8倍的空间节省意味着每页可以多存几行数据。PostgreSQL、MySQL InnoDB 都使用位图来标记槽位状态。

**Q2：删除数据时为什么不立即移动其他数据来填补空洞？**

A：移动数据代价太高。假设删除了第5个槽位，如果要把后面的数据都往前移，需要移动大量字节，还要更新所有指向这些数据的引用（索引、游标等）。"标记删除"只需修改1位，代价极低。空洞会在后续插入时被复用，或者在 VACUUM（PostgreSQL）/ OPTIMIZE TABLE（MySQL）时整理。

**Q3：HeapPage 的 tupleSize 为什么必须固定？**

A：固定大小的槽位让随机访问变得简单：第 N 个槽位的偏移 = `N * tupleSize`，O(1) 时间定位。如果槽位大小不固定（比如包含 VARCHAR），就必须顺序扫描才能找到第 N 个槽位，效率降低。真实数据库（如 PostgreSQL）的做法是：在页内维护一个"行指针数组"，每个指针记录对应行的偏移和长度，从而支持变长行的随机访问。

**Q4：一个 HeapFile 能有多少页？**

A：理论上受限于文件系统的最大文件大小。对于 4KB 页大小，如果文件系统支持 4TB 文件，则最多有 4TB / 4KB = 10亿页。实际上，JimSQL 用 `int` 存储 pageNo，最多支持 2^31 ≈ 21亿页，对应 8TB 数据，足够教学使用。

## 7. 本章小结

本章实现了 JimSQL 存储层的磁盘组织结构：

- **页（Page）**：磁盘 I/O 的基本单位，固定大小（4KB），避免 I/O 放大
- **HeapPage**：由页头、槽位图、Tuple 数据区三部分组成
- **槽位图**：紧凑的位数组，标记槽位有效性，支持 O(1) 的删除和槽位复用
- **PageId**：`(tableId, pageNo)` 二元组，全局唯一标识一个页
- **HeapFile**：多页文件的管理器，提供页的读写接口

下一章（Ch05）将在 HeapFile 之上构建**缓冲池（BufferPool）**，用内存缓存热点页，避免每次都读磁盘。

```
本章知识图谱：

磁盘 I/O 特性
  └── 以块为单位读写
        └── 以页（Page）为单位组织数据
              ├── HeapPage
              │     ├── 页头（pageId, slotCount, tupleSize）
              │     ├── 槽位图（Slot Bitmap）
              │     │     ├── isSlotUsed(slot)
              │     │     ├── setSlotUsed(slot)
              │     │     └── setSlotEmpty(slot)
              │     └── Tuple 数据区
              │           ├── insertTuple(bytes) → slotNo
              │           ├── deleteTuple(slotNo)
              │           └── getTupleBytes(slotNo)
              └── HeapFile
                    ├── PageId(tableId, pageNo)
                    ├── readPage(pageNo)
                    └── insertTuple(bytes) → PageId
```
