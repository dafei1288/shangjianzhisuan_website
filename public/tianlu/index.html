PIPELINE

一条龙的创作流水线

六个环节，一气呵成。每一步都可人工介入，也可以全部交给 AI。

  1. 壹

    剧本生成

    一个点子，展开成起承转合。

  2. 贰

    分镜拆解

    镜头语言，自动落格。

  3. 叁

    关键帧

    每一格画面，先定影调。

  4. 肆

    视频生成

    静帧起笔，运镜成片。

  5. 伍

    AI 配音

    声线入戏，旁白就位。

  6. 陆

    成片导出

    字幕音乐，一镜到底。

OPEN API

为 Agent 而生的开放接口

一把 X-API-Key，一组 MCP 工具，一条 webhook 回调——让任何 Agent 都能调度一座制片厂。

create_film.sh
# 发起一条成片任务：剧本进
curl -X POST https://api.tianlu.example.com/v1/tasks \
  -H "X-API-Key: $TIANLU_API_KEY" \
  -H "Content-Type: application/json" \
  -H "X-Callback-Url: https://your-agent.dev/webhook" \
  -d '{
    "type": "film",
    "script": "深夜，外卖员敲响了最后一扇门……",
    "style": "cinematic-noir"
  }'

# → 202 Accepted  {"task_id": "tl_8f3k…"}
# 分镜、关键帧、渲染完成后，webhook 主动回调你的 Agent
  • MCP 工具create_task / get_task / list_projects / chat 成片会话，Agent 即插即用。
  • Webhook 回调长任务异步化：提交即返回，完成时带着成片地址找上门。
  • 任务全链路image · video · storyboard · film 四种任务类型，覆盖整条流水线。
